# U-Time · 微信小程序版

> **By lyl · momoni · lele** · 设计与开发

原生 WXML / WXSS / CommonJS，不依赖桌面 DOM 或 Tauri。普通开发者工具导入后无需安装产品 npm 依赖。核心任务数据本地保存；联网插件、文件分享和局域网传输由用户主动操作。

## 打开项目

1. 微信开发者工具 → 导入项目 → 选择 `miniprogram/`。
2. AppID 与基础库版本见 `project.config.json`；更换主体时使用自己的配置。
3. 编译运行。任务表顶部可进入**收件箱、课程表、插件中心**；数据互通入口在**设置**。
4. 正式运行前核验服务器域名、隐私声明和必要授权，并做微信真机测试。开发工具中关闭域名校验不能证明正式版可联网。

## 已对齐的主要功能

| 功能 | 小程序实现 |
|---|---|
| 任务表 | 四象限、跨象限/标签搜索、今日截止/逾期/未排今日筛选、隐藏已完成、分页 |
| 排序和批量 | 长按任务上移/下移、移动象限；多选完成/恢复、跨象限移动、批量删除、清理已完成及 12 秒撤销 |
| 任务详情 | 标题、备注、项目、标签、任意整数分钟预估、截止日期/时刻、多提前量提醒；修改即时刷新并同步关联时间块标题 |
| 图片附件 | 从相册/相机选择图片、预览/移除；按 data URL 保留跨端备份兼容，页面只传本地预览路径 |
| 时间块 | 保留 7 种视图；自动/长按放置、拖动、编辑标题/日期/时长/分类、回任务池和撤销；凌晨安排自动展开全天 |
| 排程保护 | 先检查冲突再修改，只替换所选日期，不删除其他日期；取消拖动不写入，点块内文字不触发空白新建 |
| 捕获 | 中文时间识别、可改预览、完整原文、仅建任务/建时间块/暂存收件箱；跨午夜拆成两段、防连点重复创建 |
| 收件箱 | 读取跨端通知与草稿，保留结构化日期/时刻与附件；转任务、打开课程表、处理/恢复、手动整理今日/逾期待办 |
| 数据中心 | Windows/Android 封装备份与旧原始 JSON 均可导入；先预览、再确认，支持合并或替换；JSON 文件分享与复制 |
| 表格/日历 | 任务 CSV 导入/导出，时间块 CSV 导出，ICS 日历导出；当前没有通用 ICS 或 XLSX 导入 |
| 局域网 | 同 Wi-Fi、私有 IPv4 配对；探测电脑、拉取快照后预览；提交回传并查询电脑端接收结果 |

任务表每页 50 条，资料库/收件箱/课程管理每页 40 条，避免大型桌面备份一次性灌入渲染层。超长备注只预览、不因打开详情而截断原文，可导出完整文本。

新增附件最多到 6 张，每张 512KB 内；桌面导入的已有附件不会因数量超限被删除。超大的图片建议在桌面端处理。

## 内置插件：15 个清单，13 个原生适配

**原生适配不等于桌面所有功能完全一致。** 三端插件 ID、版本、启停状态与存储结构保持同源，具体能力在插件卡片上说明。

### 新增原生页面

- **课程表**：多课表、周网格/今日课程、课程编辑、单双周、自定义时间、学期/节次设置、JSON 与教务 CSV/TSV/TXT/HTML 导入、JSON/ICS 导出、课程加入时间块。保留原课表，导入先预览。Excel 可先转为 CSV。**不提供教务网页登录、脚本注入或验证码 OCR**。
- **网页收藏**：本地添加/编辑/搜索/删除、备注、跨端收藏导入导出、复制原文链接。**不自动抓取任意网站元信息，不承诺任意网站能内嵌打开**。
- **RSS 信息流**：同源 RSS/Atom/RDF 解析器、订阅管理、摘要/已读/星标、转任务、XML 与缓存 JSON 导入导出。刷新只在用户主动操作时执行，需 HTTPS 和微信合法域名配置。未读与星标不会被普通缓存裁剪丢弃；原文可复制链接到浏览器阅读。

### 保留的原生适配

番茄专注、周度报告、中国节假日、考试日历、轮换值日、拖入消息收纳、插件使用说明、微信提醒推送、竞赛消息雷达、学习通。

**学校通知网站、警大门户通知**仍未完成小程序原生适配，不把不可执行的桌面脚本伪装成可用入口。

## 跨端备份与存储安全

- 支持桌面 `format: "le-time-backup", schema: 2, data: {...}` 的封装，也兼容旧版原始状态 JSON。
- **合并**只补充缺少的记录/设置，重号保留本机；已有插件配置不会被合并覆盖。要用电脑快照完整恢复，请明确选择**替换**。
- 原始额外字段、插件存储、收件箱和桌面自动化配置保留；不会因此在小程序执行桌面 AI 规则。
- 保存主键为 `letime-data`。旧 `tidebalance-data` 只读迁移，并保留回退副本；不会自动删除旧用户存档。
- 较大快照分块保存，先写完整分块，再提交清单；失败时不拿半份数据替换原快照。损坏分块或未来 schema 会进入保护态，不用空种子覆盖。
- 导入先完整写入再切换内存；写失败不显示恢复成功。退后台时立即保存，降低防抖写入尚未执行就退出导致的数据丢失。
- 分块不等于无限容量：仍受微信总存储限制，提交新快照需要临时空间。接近上限时先导出备份，再清理缓存/附件。
- “清空当前数据”只在用户确认后执行，旧版迁移回退副本不自动删除；产品首启保持空数据，不再声称恢复示例数据。
- 备份可能包含插件登录态、推送 Token、配对码和图片，请勿向不可信的人发送。

## 局域网使用

1. 在电脑端开启“设置 → 局域网联动”，复制带配对码的链接。
2. 手机与电脑连接同一可信 Wi-Fi，在小程序设置中粘贴链接，点击“测试连接”。
3. “拉取并预览”只读取电脑，随后在备份预览区选择合并/替换并确认，才更改小程序数据。
4. 回传是**整份替换请求**，不是自动增量同步。电脑必须开启允许回传、弹窗确认，并在接收前保存恢复点；小程序不会绕过这些门槛。
5. `pending` 只是待确认，不会显示接收成功；电脑确认后点“查询接收结果”。不在后台轮询，不因关闭页面而自动批准电脑操作。
6. 使用私有 IPv4 地址（如 `192.168.1.5:27123`），不接受公网/回环地址。HTTP 局域网传输不加密，不适合公共网络。

微信版本、局域网权限、AP 隔离、防火墙均可能影响连接。失败时保留文件备份互传方案。本次实现的协议已做 mock 回归，尚未宣称在用户真实设备上联通。

## 平台限制与联网配置

- 任务提醒与插件定时检查不能保证在后台/冻结/退出后持续执行；没有伪造系统常驻、悬浮窗、全局快捷键或可靠后台响铃。
- 自定义音频路径与其他设备的本地文件路径不通用，需要在本机重新选择资源。
- 当前没有移植完整桌面 AI 自动化、原生 OCR、任意插件包动态执行或任意域名网络桥；相关备份字段仍保留。
- RSS 使用的每个请求域名都须符合微信网络要求。默认源来自桌面事实源，但是否能在正式小程序请求须逐个验证；开发工具关闭域名校验不算正式版可用。
- 原有联网插件域名包括 `notice.chaoxing.com`、`passport2.chaoxing.com`、`mooc2-ans.chaoxing.com`、`sharewh3.xuexi365.com`、`www.gxxsjs.com`、`www.pushplus.plus`、`sctapi.ftqq.com`，以实际配置为准。
- `web-view` 不等于任意浏览器：需要业务域名，个人类型小程序还有额外限制。这里默认复制外链，不创建注定打不开的内嵌页面。

官方说明：[网络能力](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)、[web-view](https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html)、[1](https://developers.weixin.qq.com/miniprogram/en/dev/api/share/wx.shareFileMessage.html)。

## 开发维护与验证

路径以下相对仓库根目录。课程模型和 RSS 解析器来自同一事实源，**不要手工编辑生成模块**。

```bash
node tools/sync-miniprogram-models.js
node tools/build-schedule-plugin.js
node tools/sync-plugins.js
node tools/sync-version.js --check
node miniprogram/tools/test-miniprogram-core.js
node miniprogram/tools/test-parity.js
node miniprogram/tools/check-miniprogram.js
```

`tools/build-schedule-plugin.js` 同时同步小程序模型；其 `--check` 会检查漂移。`le-time-management/scripts/test-miniprogram-parity.mjs` 已把小程序核心/适配/静态检查接入常规 `npm test`。

可选官方模板解析与 WXSS 语法检查：先把 `miniprogram-ci@2.1.31` 安装到独立的 `tools/.wx-compiler/` npm prefix（不改应用依赖），再运行：

```bash
node miniprogram/tools/check-miniprogram-templates.js
```

可用 `MINI_CI_ROOT` 指向其他 `miniprogram-ci` 包目录。该工具只做官方 WXML 模板词法解析、标签配对与 WXSS 语法检查，**不是完整 WCC 编译或真机视觉验收**。本次 Windows 原生 WCC addon 因缺少 `node.dll` 宿主依赖未能运行，未用解析检查冒充完整编译。

`miniprogram/tools/` 不打进产品包；课程表模型许可与归属说明保留在 `miniprogram/licenses/shiguang-schedule/`。

## 上传发布

本轮不上传、提审或发布。需发布时自行准备正式 AppID、仓库外的上传密钥及 IP 白名单，沿用原有工具：

```bash
# 在 miniprogram/ 目录中
node tools/upload-miniprogram.js --check
node tools/upload-miniprogram.js --appid wx... --key /你的安全路径/private.key -v 版本号 -d "版本说明"
```

环境变量仍支持 `MP_APPID` / `MP_KEY` / `MP_VERSION` / `MP_DESC` / `MP_ROBOT`。密钥不得入库。发布前需在微信开发者工具与至少一台真实手机上检查布局、权限、文件分享、合法域名和局域网实际连接。
