# v0.272.1 · 我的考试：把观感收干净

## 改了什么

只动 `public/plugins/cppu-notify/`（插件 1.82.0 → 1.82.1），桌面 / 安卓 / 小程序三端同源，无数据迁移。

**计数只说一次。** 统计卡第一格的大数字已经是总场数，小字从「共 4 场考试，3 场待考」改成「场考试 · 3 场待考」；搜索框下面那行 `data-exam-count` 不再报场数，只留考试计划名（原先场数在统计卡、计数行、分组标题里各出现一次）。搜索时它照旧显示「匹配 N / 全部 M」，清空后复原成计划名。

**跨度那格终于有数。** `e.md` 是 `MM-DD`（5 字符），旧代码又对它 `slice(5)`，切出空串 —— 大数字位置空着，屏幕上只剩「考试跨度」四个字，看着像没渲染完。现在直接 `replace("-", ".")` 拼成 `01.12–01.15`，首末同日只写一个；完整时间段挪进 `title`。

**时段行不再重复日期。** 卡片左边日期块已经写了「13 / 1月 · 周二」，右侧那行就只留 `14:00-15:50`，删掉后面的「· 01-13 周二」。

**回退学期那句话看情况说。** 教务没排本学期时视图会回退到最近一个学期，原来无条件写「…已经考完了」，而同一屏统计卡可能正显示「3 场待考」—— 两句正面打架。现在按**显示中的学期**还有没有待考来写：有待考就是「还有 N 场没考」，全考完才是「那个学期已经考完了」。

**三档颜色分开。** 今天 / 明天 / 后天原来只有 warn / ok 两档，「今天」和「明天」同色。现在 今天 = `live`（红、加粗）、明天 = `warn`（黄）、两天以后 = `ok`（青）。仍复用 `.jw-tag` 现有类，`test-theme-contrast.mjs` 数的「3 条硬编码 .jw-tag.ok/.warn/.live」不变。

**窄屏不拆姓名。** 考场 / 主考 / 监考各自 `<span class="jw-exam-wi" style="white-space:nowrap">`，换行只发生在两个片段之间的 `·` 处 —— 390px 下不再把「监考 冯海生」的最后一个字挤到下一行。

**对比度。** 日期块小字与「考场 · 主考 · 监考」那行从 `--ink-3` 提到 `--ink-2`；课程编号从复用 `.jw-tag muted` 改成自己的 `.jw-exam-code`（ink-2 + tabular-nums），在已结束卡的 `.58` 透明度下也读得清。

## 回归断言

`scripts/test-cppu-exam.mjs` 新增/改写的几条都盯在这次的坑上：

- `<b>01.15</b>` 必须出现（MM-DD 切片写错时这条会红）
- `01-15 周` 必须**不**出现（时段行不许再把日期写第二遍）
- 回退学期两种状态各断言一次：「还有 2 场没考」与「已经考完了」
- 计数行复原成计划名，且不许出现 `共 N 场` / `匹配`
- `class="jw-exam-wi"`、`class="jw-tag jw-exam-code"` 存在

几何用 `dev/probe-cppu-exam.mjs`（Chrome headless `--dump-dom` 读回真布局，不依赖 playwright）核过：390px 下统计区是两列、首格跨满，`document.scrollWidth - clientWidth = 0`，`.jw-exam-wi` 每个都在单行内。
