# U-Time · 更新记录

## 0.113.0

- 学习通通知和课程在应用内打开时，复用插件已验证的登录会话；Android 与桌面端均由原生端注入 Cookie，仅限 HTTPS `chaoxing.com` 域名。
- 手动 Cookie 登录也会预置到插件 HTTP 会话；外站通知链接不会携带或探测学习通 Cookie。

## 0.20.0

- 插件内部切换、列表刷新和展开新增内容时，统一获得轻量过渡反馈。
- 插件中心搜索与筛选结果按阅读顺序快速入场。
- 新动效遵循应用和系统的“减少动态效果”偏好。

## 0.14.0

- 插件入口加入独立彩色底板，右键可重命名、更换图标、导入插件和删除用户插件。
- 顶栏搜索、快捷入口、任务统计和窗口控制支持拖动换位并保存顺序。
- 设置新增“顶部任务统计居中”，设置入口改为更小的纯图标按钮。

## 0.11.4

- 插件中心删除逐项权限管理，开启 / 关闭统一使用滑块开关。
- 主导航与插件中心采用 Icons8 / iGoutu iOS Filled 图标。
- 警大门户通知正文改为原位平滑展开 / 收起，异步详情只更新当前卡片。

## 0.11.3

- 设置页新增搜索、分类筛选和吸顶导航。
- 新增界面密度、文字大小、动效、滑动翻页、顶部统计、副标题和启动页设置。
- 新增舒适 / 高密度 / 低干扰三套界面预设。
- 设置页拆分外观、插件、导航模块，降低单文件复杂度。
- 顶层状态增加统一归一化，提升旧备份和异常数据兼容性。

## 0.11.1

- 自动化批处理，显著减少重复刷新与重复写盘。
- 保存请求串行化，高频设置改为防抖持久化。
- 自动化按触发类型运行，避免无关规则反复扫描。
- 任务提醒改为自适应唤醒，降低空闲时后台轮询频率。

## v0.10.0

- 插件中心和设置页插件管理新增搜索、来源/启停筛选。
- manifest 权限从说明升级为 tide API 调用时的运行时开关；可单独撤销任务、时间块、网络、外链等权限。
- 新增全局搜索/命令面板：Ctrl/Cmd+K 搜索任务、时间块、插件与常用命令。
- 桌面安装版增加可配置的系统级全局快捷键；浏览器预览保留 Ctrl/Cmd+K。
- 时间块冲突检测升级：新增冲突预览、替代时段和插件 blocks.createSmart。
- 新增可选 WebDAV JSON 快照同步；密码只用于当前操作，不持久化。
- 微信小程序插件页新增搜索与筛选。
- 警大通知保持安全策略：只记住学号；密码不落盘；验证码仍为手动输入，当前运行会话可尝试 CASTGC 静默续期。


## v0.9.1

- 新增结构化“关于”模块：版本说明、运行环境、技术框架、开源项目及许可证入口集中展示。
- Windows / Android / 微信小程序版本号统一为同一发布版本，并增加版本一致性检查工具。
- Rust HTTP User-Agent 改为自动跟随包版本，避免升级后仍发送旧版本号。
- 设置页移除未使用代码，并把“关于”拆分为独立模块，降低后续维护成本。
- 微信小程序“关于”同步展示框架、版本说明与主要开源来源。

## v0.9.0

- 三端界面按统一的中性卡片视觉语言重构。
- 插件市场、设置、四象限、时间块、任务卡等组件统一边框、间距和交互状态。
- 保留 9 套主题，不改变 v0.8.0 的 PushPlus、通知缓存、课程表和提醒数据结构。

## v0.8.0

- 优化插件启动、HTTP 连接复用与加载性能。
- 新增 PushPlus 微信提醒主通道，兼容旧 Server酱配置。

## 0.11.0
- 数据中心：JSON / CSV / Excel / ICS 导入导出与自动备份恢复点。
- 自动化中心：截止任务自动排程、考试提醒、课程同步、每日整理。
- 统一收件箱与自动化操作日志，支持撤销自动修改。
- 警大通知与考试日历接入收件箱；课程同步支持对可移动任务进行冲突重排。
