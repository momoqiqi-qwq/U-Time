## 一、微信绿（已落地）

### 1.1 病症：成功与失败在视觉上等价

改前那份界面只有一种强调色（主题深青 `--deep` #0F4C5C），于是：

- 日志里 **✓ 与 ✗ 同为 `--ink-2` 灰**（`paintLog()` 给每行统一写 `color:var(--ink-2,#7E8B94)`）——
  「刚才推成功了没有」这件事，用户得逐字读文本才能判断；
- 预览头像是个 **P/S 字母方块**（PushPlus / Server酱 首字母）——看不出这是「微信里的消息」；
- 全页没有任何一处能一眼认出「这是微信通道」。

### 1.2 为什么不用 `--mint`

工作区里**没有 `--ok` / `--success` 令牌**，绿色语义色就是 `--mint`（#2EC4B6）——那是**青色**，
而且它已经被四象限 / 分类色占用，在插件里借它当「成功」，会和主题里的 q4 撞脸。
微信场景有它自己的品牌色，所以这份绿定义在**插件自己的作用域** `.wp-wrap` 上，不污染全局色板：

```css
.wp-wrap{--wp-wx:#07C160;--wp-wx-edge:#07C160}
:root[data-theme-mode="dark"] .wp-wrap{--wp-wx:#2AD37F;--wp-wx-edge:#25C97C}
```

深色换亮一枚是必须的：#07C160 压深色面板偏暗，实测在 15 套主题的深色变体上都发闷。

### 1.3 九处改动

| # | 位置 | 改动 | 为什么 |
|---|---|---|---|
| 1 | `ensureStyle()` 第三段 | 新增 `.wp-wrap` 品牌变量 + 深色覆盖 | 绿色只此一份，其它规则全部引用 |
| 2 | 卡头 DOM | `微信推送通道` → 左侧 26px 微信 logo PNG + 右侧状态胶囊「未配置 / 未开启 / 推送中」 | logo 是「这是微信」的唯一无字说明；胶囊替掉一整句状态描述 |
| 3 | `paintState()`（新增） | 三态：`ready && enabled` → 绿「推送中」；`ready` → 「未开启」；否则灰「未配置」 | **绿胶囊不能说谎**：未配置时立刻摘掉绿态 |
| 4 | `readFields()` / `en` change / prefs-then | 三处补 `paintState()` | 输入 Token、拨开关、读回偏好都要刷新胶囊 |
| 5 | `paintLog()` | 按行判色：`✓` → `.wp-logsuc`、`✗` → `.wp-logerr`、其它仍是 `--ink-2` | 本次改动的**核心**：成败一眼可辨 |
| 6 | `.wp-logsuc` / `.wp-logerr` | 成功 = `color-mix(in srgb,var(--wp-wx) 58%,var(--ink))`；失败 = `var(--danger)` | 纯 #07C160 压浅底只有 2 点多比 1，必须与正文色混一档 |
| 7 | `.wp-btn.pri` | `background/border-color: var(--wp-wx)` + 白字 | 「获取 Token」「发送测试消息」是主操作，绿底白字 |
| 8 | `.wp-provider button.on` + `.wp-card` | 选中态描边跟绿；卡片顶 `border-top:2px solid color-mix(var(--wp-wx-edge) 70%,var(--line))` | 渠道选中 + 卡片归属，两处低成本绿 |
| 9 | 微信预览 | 头像换成微信 logo PNG（白底圆角方块 + 24px 气泡）；`.wp-preview-note` 固定 `#6b6b6b` | 旧字母头像认不出微信；note 压在**固定浅灰底** `#e6e5e3` 上，不能跟主题走 `--ink-2`（夜间 `--ink-2` 变浅 ⇒ 浅字压浅底，改前就有的真缺陷） |

顺带清掉一处死代码：`.wp-preview-avatar{…background:#18a058;color:#fff;font-weight:750}` 与新版同权重、靠后写者胜，
留着就是埋雷，已删（头像底色改由第 1 段的 `--wp-wx` 派生）。

绿色**只落在「通道 + 成功」两处**：没有给输入框、说明段、勾格、select 上色——绿色一旦到处都是，就不再是信号。

### 3.3 测试

`scripts/test-wechat-push.mjs` 新增第 7 节 15 条断言（并同步 pluginCatalog 版本号断言）：

```js
assert.match(source, /\.wp-wrap\{--wp-wx:#07C160/);                       // 品牌绿在本插件作用域
```

## 四、影响面

- **观感**：微信推送插件从「通体深青 + 一份灰日志」变成「微信绿 + 成败分色」。
  其它 17 个插件**本版未动**——绿色改造的写法（作用域品牌变量 + 深色换亮一枚 + 语义色只给状态）可以直接搬过去。
- **行为**：`paintState()` 只读不写，不改任何推送逻辑、存储结构、攒批窗口；无迁移。
- **数据 / 三端**：`miniprogram` 走 native 适配，插件清单版本号跟随同步器；小程序侧无样式改动。
- **已知边界**：深色下「启用微信推送」这个**全局 switch 组件**仍是主题蓝——它是应用级控件不是插件自带，
  要改得动 `src/styles.css`，属另一件事（本次不动，避免一个插件改造顺手改全局控件观感）。
- **描述精简（本版未动手 → 已在 v0.200.0 落地）**：第二节是清单，用户拍板后由 v0.200.0 一次性改完并补了第 8 节守卫断言。
