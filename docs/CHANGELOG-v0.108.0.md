# CHANGELOG · v0.108.0

## 底栏 / 设置 / 交互（外观与交互逻辑专项）

### 新增：底栏可视化设置（设置 → 外观）
- **底栏形态**：「悬浮玻璃」（默认，四周留缝浮起）/「贴底」（通宽压平，v0.105 之前的形态）。
  贴底档只把悬空量 `--nav-float` 归零并收口四角 —— 几何消费方（left/right/bottom、
  出入场关键帧）全部读同一个变量，一处设置全局联动。
- **底栏材质**：「毛玻璃」（默认）/「实色」。实色档关掉 `backdrop-filter` 实时模糊、
  底色提到不透明 —— 低端 WebView 上模糊是滚动掉帧的大头，这一档换流畅与续航。
- 两项与既有的「底栏高度」一样只影响 ≤900px（手机端），桌面无感。

### 修复：悬浮玻璃底栏遮内容
- 底栏呼出期间，页面内容此前只让出「4px + 安全区」—— v0.106.0 改悬空玻璃后条子
  浮在屏幕底缘上方，且呼出态在切换视图后保留，内容最后一行一直被玻璃盖住
  （看得见点不到）。现在呼出期间 `.view` 让出「条高 + 悬空缝 + 余量」，
  条子永不遮内容；沉浸式页（课程表）不挤压布局，靠「点空白即收起」。

### 交互逻辑
- **呼出态点空白即收起底栏**：此前只有「再按 ⋮ / 打开设置」能收，与 Android
  「弹出的面板点外部即收」的习惯相悖。现在点底栏与悬浮键之外的任何位置即收，
  且不抢点击 —— 点到的控件照常工作。
- **滑动语义不再打架**：全局「左右滑动 = 返回上一页」此前与课程表周视图
  「左右滑 = 切周」同时命中，一次滑动既切周又退回上个视图。现在插件页
  （.plugview）内的横向手势归插件自己，全局滑动返回只在核心页生效。
- **软键盘让路**：输入框聚焦（键盘弹出）时，两颗 45% 高度的悬浮键（‹ / ⋮）
  自动淡出并停吃点击，不再压在聚焦输入框上；失焦即恢复。
- 节次文本框等高个输入控件的悬浮键走廊（v0.107.0）保持不变。

### 影响范围
- `src/uiPreferences.js`（新增 navDock / navGlass 偏好 + data-nav-dock / data-nav-glass）、
  `src/views/settings/appearance.js`（两行新设置）、`src/styles.css`（形态/材质消费方 +
  呼出态让位 + 键盘让路）、`src/shell.js`（点空白收起 + 焦点监听 + SWIPE_SKIP 追加）。
- 新偏好有默认值与归一化兜底，老存档无感升级；无数据迁移。
