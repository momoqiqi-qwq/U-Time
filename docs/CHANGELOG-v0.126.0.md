# v0.126.0

- 新增「警大校历」内置插件：按月查看警大教务当前学期的教学周，支持手动设置学期和保存个人校历事项。
- 校历通过插件事件向「警大门户通知」请求当前学期起始日和教学周数，复用现有登录会话；只交换学期边界数据，不传递账号或票据。
- Windows 与 Android 共用插件页面；微信小程序暂标记为不可用。校历事项使用插件私有存储，无数据迁移。
- 教学周是按教务提供的起始日和周数推算，不能代表放假、考试和调课的正式安排。
- Android APK 底栏改为常驻：启动即显示、点击页面不再自动收起、进入课表时继续显示，且不播放进出动画或允许拖动快捷按钮。
- Android APK 底栏新增“成绩”和“课表”直达入口；对应插件未启用时提示前往插件中心。桌面端行为不变，无需数据迁移。
