# v0.119.0

## 更新内容

- AI 对话深色模式中的用户消息气泡改为更沉稳的底色。
- 新增 `tide.messages.publish()`：消息类插件可公开当前列表摘要，宿主与新消息广播合并、去重后供 AI 读取；不触发微信推送，也不暴露插件私有存储。
- GitHub 文档修正子目录 README 路径拼接；提交订阅不可用时改走 GitHub commits API 备用路径，并保留具体错误信息。

## 影响范围

Windows、Android 的 AI 对话、消息类插件及 GitHub 文档插件。

## 数据迁移

无需迁移；宿主消息摘要仍为运行期数据，AI 对话继续保存已收集的消息摘要。
