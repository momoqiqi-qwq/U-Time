# CHANGELOG · v0.114.0

## 内置网页侧边栏工具箱

- U-Time 应用内网页窗口新增右侧竖向工具栏，**刷新网页固定为第一项**，并提供后退、前进、收藏/收藏列表、复制网页地址及 75%–150% 页面缩放。
- 工具栏使用 Shadow DOM 与网站样式隔离，只挂载在最外层网页；普通网页窗口与学习通带登录态窗口共用。
- 收藏数据写入当前站点 WebView 的本地存储，不会跨站共享；不向外传送 Cookie 或新增数据迁移。

## 影响范围与迁移

- 影响 Tauri 桌面端与 Android 的应用内网页窗口。
- 无用户数据结构迁移。
- 构建与自动化验证不替代实体 Windows / Android 设备上的按钮和刷新验收。
