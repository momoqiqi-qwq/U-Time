## 用户要求

> 一堆根本不是人名的东西获奖

榜单实测出现「教务处 3 项」「等线 2 项」「仿宋 2 项」「宋体 2 项」「无列表 2 项」，
和真实获奖人（周子衿 4 项等）排在同一张榜上。

## 一、根因：级别行一旦出现过，就永久生效

`parseAwardNotice()` 收「单行单名」时要判一行是不是真名，旧写法只问一件事：

```js
if (value.length <= 8 && !label && items.length === 1 && items[0].kind === "person") {
  if (!ctx.level) continue;   // 旧：只在还没见过奖级时放行
}
```

`ctx.level` 是**扫码器式的粘性状态** —— 正文里出现过一次「一等奖」，之后每一条孤零零的
2–4 字短行都被当成获奖人。而这些短行真实身份是：

| 漏进来的东西 | 从哪来 |
|---|---|
| `等线` `仿宋` `宋体` | 附件是 `.doc`（OLE）时只能按 UTF-16LE 粗扫，**字体表**跟正文一起被扫出来 |
| `无列表` | 同上，Word 的**样式表/列表样式名** |
| `教务处` | 通知末尾的发布单位（落款） |

它们在形状上和人名完全一样（2–4 个纯汉字），形状判定救不了，必须补词表 + 补场景。

## 二、修法：名单区 + 词表 + 机构尾字

三处一起改，缺一处榜上仍有假名：

| 层 | 判定 |
|---|---|
| 场景 | 新增 `rosterZone`：命中「获奖名单 / 名单如下 / 获奖人员 / 表彰名单」等开启，遇**空行**或**句末标点的说明句**（`。；;` 结尾且长度 ≥ 12）关闭。单行单名只在 `rosterZone` 里才收 —— 脱离名单区，一个孤立的短行**没有获奖证据**，宁少不滥 |
| 词表 | `NOT_NAME_FONT`（等线 / 仿宋 / 宋体 / 黑体 / 楷体 / 微软雅黑 / 方正 / 华文… + 无列表 / 正文 / 标题 / 页眉 / 页脚 / 目录 / 参考文献 / 模板…）、`NOT_NAME_ORG`（团委 / 党委 / 工会 / 教务 / 学工 / 后勤 / 财务 / 保卫 / 科研 / 办公 / 机关 / 学生会…） |
| 尾字 | `ORG_TAIL = /[处务科所站馆局厅委办署司厂社部室系院校队组班级]$/`：3–4 字且以机构尾字收尾的一律不是人名（补上 `[学院校系室部中心队伍组队班级年级]` 漏掉的 `处` `务` 那一路） |

三层判定收进 `isPersonName()` 一个出口，附件表格层（`looksLikePersonCell`）用**相同的三张表**，
两层注释互指、测试交叉断言 —— 同一份名单走正文和走附件，结论必须一样。

## 三、名单区不能修得过头

守卫断言盯着「级别行 + 纯姓名行」这种最常见的真实写法：

```
获奖名单如下：
一等奖
周子衿
肖亦嫣
```

仍然要读到三个人。空行只在「名单没结束就空了一行」时关区，
下一行只要还是级别行或名单标签行，会重新开区。

## 四、团体获奖不再用队名署名（连兜底也不要）

用户原话（第二条）：

> 都说了不要用「队名」

上一版（v0.213.0）已经把**有成员名单**的团体改成按成员署名，但留了一条兜底：
通知只写了队名、没按人列成员时，仍然把队名当署名，并在行内注明「通知未列成员，署名仍用队名」。
截图实测：团体档上仍然挂着 `侦查学院代表队`、`无成员代表队` —— 队名还是出现了，这条兜底就是漏口。

口径收紧成一句话：**没有姓名可署名，就不署名，也不许拿队名顶替。**

| 位置 | v0.213.0 | v0.214.0 |
|---|---|---|
| 获奖排名 · 团体档 | 有成员 → 成员姓名；没成员 → **队名**+注明 | 只收「按人列过成员」的队，行名 = 成员姓名；没列成员的队**整条不进榜** |
| 团体档行的 key | `t:队名`（`data-aw-item` / `data-aw-toggle` 里看得见） | `t:赵六、钱七` —— 源码里也没有队名 |
| 团体档展开 | 悬停气泡 `title="…原队名 X"` | 气泡、标题、注解一律不带队名 |
| 奖项项目 · 团体条目 | 没列成员 → 单独一组「…署名仍用队名」贴队名 pill | 换成「N 个团体获奖未列出成员姓名（无姓名可署名，不计入本页）」——只报个数 |
| 统计行 | `署名到人 N 位（团体获奖按成员署名）` | `署名到人 N 位` + 需要时 `另有 N 个团体获奖未列成员姓名` |
| 人名榜来源标 | 只标「团体」（`aw-tag team`） | 不变，类名改 `aw-tag grp`（`team` 这个词也一起从样式里去掉） |

**为什么不干脆把那几条记录整条藏起来**：藏了就是静默丢数据，用户会以为「人漏了」。
现在的做法是保留条目（日期 / 项目 / 级别都在），只在人数统计里明确报出「有 N 个团体没列成员」——
消息不丢，署名不脏。

`awardBearer()` 的兜底也一并删掉：团体没成员时返回空串，不再返回队名。

## 已知副作用（有意接受）

- 3–4 字真名若以机构尾字结尾（如「张明科」的「科」）会被挡 —— 机构名「教务科 / 学生科」
  在通知里出现的频率远高于这类名字。
- 空行之后的孤立姓名行不再计入名单区（真实通知的名字行都紧跟在级别行/名单标签行之后）。
