# v0.242.2

> 归属说明：本版并入两批互不相关的改动，均属于「未提交、未打 tag」的在途批次 —— 按仓库惯例
> （v0.38.0 先例）追加改动并进本版，不另造新版本号。① 学习通插件作业探测 40 秒冷却；
> ② 警大门户插件「一卡通」与「学生请假」两处汇总卡补徽章图标。

## 改了什么

学习通插件（`chaoxing-notify`）的作业提交状态探测加了**按记录 40 秒冷却**：过去 40 秒内已获取过消息的作业记录不再重复拉取，40 秒之后才能再拉取。

- 探测入口有三条，全部汇到 `probePendingWorks()`：打开插件时的自动刷新（默认策略）、手点「刷新」、任务栏角标每 5 分钟的后台刷新。此前这三条入口连着触发时，同一批「未提交」作业会被反复打给学习通——探测是串行的，用户体感就是「刷新了一次，作业状态却半天不动，其实都在重探同样的几条」。
- 冷却按 `workId` 逐条记（复用原有 `probeTimes` 时间戳表，该表此前只用于排序）：同一作业 40 秒内跳过，超期后自动回到候选队列；从没探过的新作业不受影响，冷却期间照样排进来，因此每轮分批仍稳定往后推进，不会围着最先几条打转。
- 探测失败（网络抖动 / 会话过期）同样记时间戳——请求已经打出去了，冷却照样生效；下一轮刷新通常隔好几分钟，自然重试，不会趁着失败连续重打。
- 已探到「正在批改」的记录与以前一样永远跳过（状态不变就没有再探的必要）。

## 影响哪端

Windows / Android 两端的学习通插件视图（作业探测只在桌面壳与 App 内发生）。小程序端 `chaoxing-notify` 为原生适配、无探测逻辑，不受影响。无新增权限、无新增存储键（`probeTimes` 仅存内存，不落盘）。

## 数据迁移

无。`workStatus` 等既有存储键的结构与口径不变。

## 追加：警大门户插件两处汇总卡补图标

### 改了什么

`cppu-notify` 插件的两处汇总卡从「纯文字」变成「图标 + 数值」：

- **一卡通三张统计卡**（`.yk-stat`）：总充值量 = 蓝 · 硬币加号，已花费 = 橙 · 购物袋，当前余额 = 绿 · 硬币叠层。图标与金额并排（`.yk-amount`，图标 28px / 金额 30px），标签仍在上、说明仍在下，卡片信息层级没动。
- **学生请假首屏汇总卡**（`.jg-metrics` 四项）：申请总数 = 蓝 · 单据，已同意 = 绿 · 对勾，审批中 = 橙 · 沙漏，未通过 / 已撤销 = 红 · 叉。图标与「数值在上、标签在下」并排（`.jg-metric`，图标 26px / 数值 19px），四档配色（good / warn / bad）原样保留。

请假汇总卡的图标不是新需求——今天白天已有设计稿（`docs/design/leave-badges/`，六边形徽章 PNG），但**从未接进代码**，用户在真机上看到的汇总卡因此一个图标都没有。

### 走过一次弯路：六边形 3D 徽章 → 纯线条图标

第一版按设计稿把七枚六边形 3D 徽章（图片生成产出、裁成 112px 透明 PNG）接了进去，用户看后否掉：**「太丑了，且不要外面的六边形了」**。六边形底板本质上就是给图标套了一层彩色背景块 —— 同一个坑 v1.60.0 在校历图标上已经踩过一次，v1.60.1 才删干净；这版又踩回去，说明「底板 + 白图形 + 投影」这套语言和本插件其余界面（扁平卡片 + 线条侧栏图标）根本不搭。

第二版改用**内联 SVG 纯线条**，与校历 `cal-icons.js` 同一套语言：线内着色、线外一律全透明、无底板无 rim 无高光无投影。七个图形画在标准 24 网格上（stroke 2.2、圆头圆角），`width/height` 就是视觉尺寸。

图片生成的实测结论也记一笔：**几何图标不适合交给生图模型**。同一批提示词（「扁平、单色、粗线条、无底板」）出来的勾号被画成一个「D」形方框、单据被画成三行虚线、存钱猪细节碎到 36px 下糊成一团；硬币加号、购物袋、沙漏、叉这四枚才勉强能用。而这类图形用矢量描述只要几行路径，且任意尺寸都不糊。

### 为什么是内联 SVG，不是 PNG 也不是图片生成

| 决策 | 选了什么 | 为什么不选另一条 |
|---|---|---|
| 载体 | 内联 `<svg>` 字符串（`metricIcon(key, size)` 在 main.js 里） | 位图要为 16 套主题 × 浅/深两态各出一张；图片生成对几何图形不可靠（见上）；108KB 的 base64 内嵌还会给 main.js 平白增重 |
| 网格 | 标准 24 网格、stroke 2.2、圆头圆角 | 先按 96 网格画（照校历），结果 44px 盒里图形只占 22px（留白吃掉一半），比例偏小；24 网格下 width/height 即视觉尺寸，不用再猜缩放 |
| 颜色 | 每枚一个语义色，取「白卡与深紫卡上都够看」的中间调（对 `#FFF` ≥3:1、对 `#232029` ≥4.6:1） | 按 `data-theme-mode` 出两套色板要多维护一倍；中间调在 16 套主题下都过 AA |
| 图形 | 充值 硬币加号 / 花费 购物袋 / 余额 硬币叠层；申请总数 单据 / 已同意 对勾 / 审批中 沙漏 / 未通过 叉 | 六边形徽章（已否）、猪存钱罐（24 网格下细节留不住）、钱包（28px 下读成电池）都试过 |

### 影响哪端
