# v0.162.0

- 设置页移除设置行之间的横向分隔线，保留分区外框与行间留白。
- 文本、数字、时间、下拉选择和多行输入控件平时隐藏背景与描边，点击或键盘聚焦时显示编辑框，失焦后恢复；开关、滑杆、颜色与文件选择器保持原有外观，适配浅色、深色和 Nephele 风格。
- 设置窗口左下角新增“左侧分类”按钮，右下角新增“顶部分类”按钮，可随时切换分类栏位置。
- 当前位置高亮显示，选择自动保存；关闭设置或重启应用后保留。
- 切换布局保留当前分类、搜索条件和未保存的控件输入，支持默认及 Nephele 风格，并按分类方向支持键盘导航。
- 影响端：Windows 与 Android 共用的设置界面；小程序仅同步版本号。
- 数据迁移：无需迁移，新增界面偏好字段，旧数据保留原有默认布局。
