# v0.289.0 · 时间线与插件中心查询优化

## 改动

- 时间线每轮渲染只建立一次任务索引，关联排程的正文与节点签名共用查询结果，避免每张卡片重新扫描整个任务列表。保留重复任务 ID 时首项优先的既有行为，并区分关联任务不存在与存在但没有标题，确保添加、删除、改名后及时刷新。
- 插件中心每轮构建或刷新共用一份按插件分组的视图索引；组头入口数量一次汇总，卡片与组头直接查询索引，避免逐卡片、逐分类反复扫描插件视图与插件列表。异步注册和移除视图时重新索引，保持入口顺序与零视图插件计为一个入口的规则。
- 保留未变化的时间线节点、插件卡片及其滚动、焦点、展开状态。

## 影响范围

- Windows / Android 共用的时间线、插件中心渲染路径。
- 小程序仅同步版本号，不改变其业务行为。
- 无数据结构变更，无数据迁移，无新增依赖。
- 工作区原有插件卡片调整与其他并行改动保留，不构建或发布安装包。

## 验证

- 时间线规模回归：1,200 个任务、1,200 个关联时间块，任务 ID 读取从旧实现 721,800 次降至 1,200 次；覆盖关联任务增删改、重复 ID 首项语义及节点复用。
- 插件中心行为与规模回归：160 个插件、8 个分组、480 个视图，每轮建卡或刷新均只读取 480 次视图归属；覆盖分组计数、异步注册/移除、筛选及卡片增量刷新。
- `sync-version.js --check`、`gen-theme-dark.js --check`、`build-schedule-plugin.js --check`、`sync-android-native.js --check`、`sync-plugins.js --check`：全部通过。
- `npm test`：166 个测试脚本全部通过，验证期间产品与测试文件未变化；验证工作区已包含并行会话的 v0.290.0 自动登录改动。
- `npm run build -- --outDir <独立临时目录>`：前端生产构建成功，495 个模块；使用独立输出目录避免与并行会话共享 `dist/`。
