# v0.296.0

## 轮换值日总面板

- 轮换标签栏最前新增「总面板」，默认汇总所有轮换的今日值日人；多人值日和临时换人均显示实际完整名单。
- 一套轮换占满可用区域，两套在宽屏并排均分，窄屏上下排列；更多轮换自动排成网格。总面板显示今日地点、本轮日期与下一轮安排。
- 暂停、尚未开始、没有成员分别显示对应状态。点击「管理轮换」或原组名标签可进入原有详情编辑。
- 标签切换复用宿主滑动选中光，遵循减少动效设置；跨天及其他轮换数据变动时刷新总面板。

## 影响范围与数据

- Windows / Android 共用插件界面，微信小程序同步提供原生总面板。
- 排班、成员、提醒与备份格式保持兼容，无需迁移排班数据；新增独立的 `panelView` 偏好，仅保存 `overview` / `group`，保留 `activeId` 的原含义。

## 验证

- 桌面行为测试覆盖默认总览、单组/双组、多人成员与临时换人、地点、暂停/未开始/无成员、回到详情、跨天与非当前组刷新。
- 浏览器检查桌面与窄屏布局、浅色/深色、选中光中间帧、快速切换及减少动效；按仓库要求执行版本、生成物与全量测试。
