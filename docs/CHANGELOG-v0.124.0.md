# v0.124.0

## 改了什么

- 首次安装后启动会记录当前版本，并在软件右下角提示“安装完成”。
- 覆盖安装新版并重新启动后，会比较上次运行版本与当前版本，在右下角提示更新成功及版本变化。
- Windows 任务提醒接入系统通知中心；主窗口隐藏到托盘时，应用仍在运行即可弹出 Windows 系统通知。
- “设置 → 任务提醒”新增“测试提醒”按钮，可同时验证应用内横幅、提示音和系统弹窗。

## 影响范围

- Windows 桌面端：新增系统通知与安装结果提示。
- Android：保留既有原生通知和后台闹钟逻辑，未改变排期机制。
- Web 调试模式：保持安全降级，不发送原生系统通知。

## 数据迁移

- 无业务数据迁移。
- 首次启动会新增本机版本记录 `letime-installed-version`；发起应用内更新时会短暂写入 `letime-pending-update-version`，安装结果确认后自动清除。
