# v0.134.0 · 侧栏插件拖动跟手与高亮

- 被拖动条目和浮起副本均保持不透明，改用主题色高亮底色、实线描边，不再降至 18% 透明度。
- 指针移动立即更新副本位置；排序测量合并到一帧，静止时不空转。保留按下位置锚点、移除跟随缩放偏移，鼠标激活阈值由 6px 降至 4px。
- 同一条目新的让位动画接管前取消旧动画，避免快速反向时叠加拖尾；让位缩短至 120ms，松手落位缩短至 140ms。
- 松手同步最终坐标，不漏掉最后一帧；滚动后重算容器坐标；支持 Escape / 窗口失焦 / 调整窗口时取消恢复顺序。
- 减少动效模式仍保留直接跟手副本，跳过装饰性让位/落位动画。保留触屏长按、普通滚动和 Alt+方向键排序。
- 新增行为回归覆盖跟手、帧合并、快速反向、松手、滚动、缩放、取消、触屏及高亮。真实桌面/触屏手感与视觉仍需人工验收。
