# v0.299.0

## 新增「考勤风险」视图（cppu-notify v1.92.0）

- 把 cppu-helper 的 \`AttendanceRisk.compute(meetings, absences)\` 搬进 U-Time：按本学期课表算每门课的排课次数，再叠请假单里的审批结果，给出「这门课还能缺几次」。
- 额度口径与原版逐条一致：\`totalHours = sessions × 2\`（1 次课 = 2 学时），\`allowed = trunc(trunc(totalHours / 3) / 2)\`。两步都取整，不是一次 \`/ 6\` —— 30 次课的课 = 60 学时 → 额度 10 次，原版就是先除 3 再除 2，改成单步会在某些次数上多算一次。
- 三态计入：\`SQZT\` 为 \`2\` 或 \`3\` 都算**已批准**（原版同样两态都进 approved 分支），\`1\` 算审批中，其余算未通过。请假单上出现了课表里没有的课程名，直接丢掉 —— 没有排课次数就说不清额度，原版也是这个口径。
- 红线两条，任一命中即「已超红线」：① 已批准次数 > 额度（这门课已经不能再请）；② 未通过满 3 次（按旷课折 2 学时一次 = 6 学时）。没超线时再按剩余次数分三档：0 次「额度用完」、1 次「仅剩 1 次」、其余「安全」。
- 每门课一张卡：排课次数 / 总学时 / 已批 / 审批中 / 未通过五枚标签，下面一条进度条把「已批」画成实心、「审批中」画成斜纹（斜纹 = 还没落定，批下来就变成实心），再两句话说明「还能缺几次」与「再请几次会变成审批中堆积」。
- 排序：已超红线 → 剩得最少 → 课时最多。最该看的排最前。
- 页面顶部四格摘要（有风险课程 / 已到红线 / 审批中 / 合计还能缺），页脚写明口径，不编数：请假记录这次没拿到就只算额度并注明「未计入已批准」，课表还没同步就直说先去课表页同步一次 —— 不假装「0 次旷课」。
- 旷课条款按学时还原：2 学时 / 次，10 学时（5 次）警告或严重警告、30 学时（15 次）记过或留校察看，未到线时写「距警告线还差 N 学时」。

## 自习室新增「只看空」

- 选定某一节（不是「全时段」）后，筛选条上出现可点的「只看空」：一键把这一节有课的教室藏掉，计数同步变成「这一节空闲 N 间」。切回「全时段」自动复位并置灰 —— 不复位就会按钮变灰而状态仍为真，教室被无声过滤掉。
- 走的是和关键词过滤同一套 DOM 就地显隐（\`row.hidden\`，不重绘），所以不会丢输入焦点、不打断拼音输入。
