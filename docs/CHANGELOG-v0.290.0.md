# v0.290.0 · 自动登录与会话恢复加强

## 警大门户（插件 v1.89.0）

- 恢复 Cookie 和密码兜底登录合并并发请求，门户、教务、个人信息共用同一次登录结果；空 HTTP 运输会话仍会恢复磁盘 Cookie，避免先打开个人信息后错误跳过恢复。密码兜底失败后暂停自动尝试 30 分钟，人工登录仍可立即操作。
- 密码、Cookie 与个人信息 token 绑定账号，兼容已有密钥库格式。关闭自动登录后不再恢复或保存持久化登录信息；本次手工登录可继续使用内存会话。
- 清除密码、切换账号及停用插件使旧异步操作失效。清理进行中也禁止新恢复读取尚未删除的凭据，密钥库写入和删除按顺序完成；旧账号通知响应不会覆盖新账号通知或缓存。
- 预热在读取设置前取得互斥，回到前台和网络恢复时重新检查；离线不算登录失败，未来或异常时间戳不造成长期停用。成功仍按 12 小时节流，失败按 30 分钟退避，停用插件移除计时器和监听。

## 学习通（插件 v2.23.0）

- 密码和 Cookie 迁入本机加密密钥库；确认写入成功后才移除普通插件存储中的旧值。密钥库不可用时不新增明文保存，并提示用户；历史值迁移失败时保留原值以避免丢失登录信息，之后可重试迁移。
- 区分明确的会话过期、网络或服务异常、账号拒绝。临时失败保留凭据；账号错误或平台要求验证时暂停自动尝试，交给用户手动登录。
- 首次恢复、收件箱和课程域恢复共用并发控制。自动密码登录 30 分钟内不重复，失败与拒绝状态跨重启保留；明确过期时仅恢复并重放一次请求。
- 切换账号清理通知、课程、课件、作业状态及相关缓存；旧账号迟到的登录结果不能复活会话。重复点击登录不会产生并行提交。

## 范围与数据兼容

- 影响 Windows / Android 共用插件；小程序同步应用版本与插件目录元数据，登录业务未改动。
- 无新增依赖，无任务或排程数据迁移；凭据迁移仅发生于本机。验证码识别与平台认证协议保持既有实现。
- 本次为源码更新，未发布安装包，也未替换本机运行版本。
