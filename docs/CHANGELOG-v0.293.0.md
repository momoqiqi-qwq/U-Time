# U-Time v0.293.0

## HTML 目录（新插件）

- 侧栏新增「HTML 目录」：指定一个文件夹，自动认出里面所有 `.html`（含子文件夹，最多 6 层），铺成卡片，卡片里直接渲染首页的真实画面，不是截图也不是图标。
- 卡片宽度按可用空间自适应分栏；拖卡片右边、下边、右下角三条边框改大小（光标分别是 ↔ / ↕ / ↘），尺寸按页面分别记住，重开还在。
- 点卡片看整页：全屏浮层里加载完整页面，Esc 或点空白处关闭。
- 目录选择器：常用位置（桌面 / 文档 / 下载 / 各磁盘）一键跳转，逐层进入，每个子目录标出直接包含的页面数，不用挨个点进去找。
- 记住上次选的文件夹，下次进插件直接出图。可切换「含子文件夹」与「只看这一层」。

## 预览为什么需要一个本机服务

- 新增 `src-tauri/src/html_gallery.rs`：一个只绑 `127.0.0.1` 的静态服务 + 目录扫描命令。
  iframe 要能加载页面，页面里的相对路径 css / js / 图片就得跟着能取到；把 `file://` 塞进 iframe 会被 WebView2 拦掉，所以走普通 http。
- 只服务选中文件夹里的文件：路径逐段拒绝 `..`、盘符与反斜杠，落盘前再 canonicalize 比对一次前缀，`%2e%2e%2f` 这类编码绕过同样拦下；单文件上限 48MB。
- 页面标题优先按 UTF-8 解，失败退 GB18030 —— 老 GBK 页面不会显示成一串乱码。
- 换文件夹时旧服务先停再起；插件视图关闭时一并停掉，不留监听端口。

## 插件接口

- 新增权限 `localFiles`（读取用户选中的本地文件夹）与 `tide.localHtml`：`roots` / `list` / `scan` / `serve` / `unserve` / `status`。
- `scripts/test-plugin-permissions.mjs` 的命名空间映射表同步登记；`tools/gen-plugin-icons.py` 增加 `html-gallery` 图标行。

## 边界

- 全程只读：不写、不删、不改被浏览的文件。
- 预览是真实渲染，页面里自己的网络请求照常发出（和用浏览器打开一样）。
- 微信小程序端不提供（`unavailable`）：那边没有本地文件系统。

无数据结构变化，无迁移。
