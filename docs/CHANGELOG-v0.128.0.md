# v0.128.0

- Android：首次启动自动申请 Android 13+ 系统通知权限，申请记录保存在原生本机存储；拒绝后提供通知设置入口，不在每次启动重复申请。
- Android：插件 `notice:new` 新消息按来源汇总到系统通知栏，复用已有通知渠道；插件消息不显示任务“标记完成”按钮。插件网络刷新仍依赖应用运行，已排期的任务由原生闹钟负责后台提醒。
- Android：原生通知返回真实发送结果；未授权、渠道关闭或发送异常不再报告成功。精确闹钟提供系统授权页入口。
- APK / Windows：首次使用显示使用说明与免责声明，“我已阅读”记录仅保存在本机；“设置 → 关于”可随时查看。
- 无用户数据迁移。
