# v0.151.0

## 更新历史
- 顶部和设置 → 关于新增「更新历史」按钮，在应用内查看按版本倒序排列的更新记录。
- 展示当前版本、检查状态和可独立滚动的版本卡片，随应用打包现有 CHANGELOG，离线可查看。
- 弹窗适配浅色、深色、窄屏和 Android 安全区，支持 Escape 关闭及键盘焦点管理。

## 顶部默认布局
- 默认采用左侧更新历史与云同步、中间搜索、右侧日志、深浅模式、设置及窗口控制的紧凑分布。
- 云同步进入现有同步设置；日志查看现有自动化记录。
- 无存档或仍使用旧默认顺序时采用新布局，保留已有自定义顺序和拖动排序能力。

## 影响与兼容
- 影响 Windows / Android 共用前端，顶部新分布仅应用于桌面宽度；小程序仅同步版本。
- 无业务数据迁移，不修改任务、日程、账号或插件数据。
