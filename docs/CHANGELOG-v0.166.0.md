# v0.166.0

## 改了什么
- 可选同步的三张网盘选项卡改为下拉选择栏：收起时显示当前网盘和简介，展开后按行选择，选中后自动收起。
- 网盘列表、应用密码说明和局域网准备说明均补齐展开与收起动画，容器高度、内容显隐和方向箭头连续过渡。
- 下拉选择支持方向键、Home / End、Enter / Space、Escape 和点外部收起；关闭时禁用内部焦点，保留账号与可编辑地址草稿，选中光块复用公共滑动效果。
- `AGENTS.md` 新增下拉栏双向动画规范，要求实际验证中间帧、连点接续、减少动效与最终布局。

## 影响哪端
- Windows / Web / Android 设置界面。小程序仅同步版本号。

## 数据迁移
- 无数据迁移。沿用原有 WebDAV 配置与本机密码存储。
