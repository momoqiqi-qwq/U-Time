# v0.170.0 · 值日名单拖动重排

> 补记：这一版发布时漏了本文件，应用内「更新历史」因此缺了一版。内容按提交 00bea2e 补写。

## 改了什么

- 「轮换值日」插件里拖动成员改顺序时，被拖的那一行与「今天当班」那一行统一用主题绿描边标出（走 `outline`，不吃布局、整行高度不会跳）；当班行另外加一层淡绿底和绿色序号，「今天当班」一眼就能看出来。
- 序号在拖动过程中按槽位实时重编，松手不再出现「1..6 集体跳一次」。
- 其余成员行用 WAAPI FLIP 从旧位置滑到新位置，让位动画与侧栏拖动同一套手感；系统开启「减少动态效果」时直接短路，不做动画。
- 位移超过 4px 才进入拖动态（与参考实现 PointerSensor 的激活距离同值），轻点不会误触发排序。
- 在 document 捕获阶段兜底 `pointerup` / `pointercancel`，触摸第二指或系统打断时拖动会话不会挂死。

## 影响范围与数据迁移

- 仅内置插件「轮换值日」，插件版本 1.7.0 → 1.8.0；Windows / Web / Android / 小程序三端插件同源。
- 无数据迁移；轮换顺序的存储字段未变。
