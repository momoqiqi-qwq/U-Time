Before you start / 通用步骤

从侧栏「插件」进入

内置插件首次发现时默认启用。插件页会自动出现在侧栏；移动端先进入底栏的「插件」，再从卡片进入具体功能。

  1. 01打开插件桌面端从侧栏直接进入，或点「插件」查看全部卡片；移动端打开底栏的「插件」入口。
  2. 02完成首次设置多数插件开箱即用。校园通知、微信推送和课程表需要账号、SendKey 或学期信息。
  3. 03管理启用状态进入「设置 → 插件」可停用、启用或重新扫描。内置插件不能删除，关闭后可从侧栏和插件页移除。

番

番茄专注

pomodoro

专注

环形倒计时专注工具。选择任务后开始 25 分钟专注，可切换 5 分钟短休和 15 分钟长休，完成的番茄会计入累计统计。专注 / 休息结束可分别设置通知与提示音，提示音有 7 种内置音效，也可以导入自己的音频。

提醒可配置选择任务可选本地统计

怎么用

  1. 打开「番茄专注」，在下方选择要关联的任务，也可以保持“不关联任务”。
  2. 选择“专注 25”“短休 5”或“长休 15”，点“开始”；再次点击可暂停，点“重置”恢复本轮时长。
  3. 展开「提醒设置」：专注结束和休息结束可以分别开关「通知」与「声音」，挑一个内置提示音点「试听」就能听。
  4. 想用自己的音频，在「自定义音频」里点「导入」选一个本地文件（4 MB 以内），「清除」可随时退回内置音效。
  5. 完成后查看页面底部的累计个数和分钟数，并回到四象限或时间块继续处理任务。

计时器只在当前应用运行期间持续。需要后台或锁屏提醒时，请配合“微信提醒推送”或系统级提醒使用。

报

周度报告

weekly-report

复盘

自动汇总过去 7 天的时间块、分类占比、每日分布和任务完成度，用来快速看清一周的时间投入。

无需配置读取本地数据自动更新

怎么用

  1. 先在日常使用中把任务排进四象限和时间块，并尽量选择正确分类。
  2. 打开「周度报告」，查看过去 7 天的柱状分布、各分类时长和任务完成比例。
  3. 用报告发现偏科后，回到时间块调整下一周的安排。

报告只统计当前本地数据。分类主要由任务和时间块的类型决定，记录越完整，结果越有参考价值。

假

中国节假日

cn-holiday

日历

查询法定节假日、调休上班日和下一次休息日。内置 2024 至 2026 年离线数据，缺少年份时可以联网更新并缓存。

内置离线数据联网可选无需登录

怎么用

  1. 打开「中国节假日」，首页会显示今天的状态、下一个假期和距离下个休息日的天数。
  2. 用“查某一天”选择日期并查询，可以判断这天是放假、调休、普通周末还是工作日。
  3. 在下方切换年份查看全年安排；需要更新时点“联网更新”。

数据源为 holiday-cn，依据国务院办公厅公开安排。重要行程仍建议以官方最新通知为准。

考

考试日历

exam-calendar

学习

汇总四六级、考研、教师资格、计算机等级、专四专八等大学生国家级考试，提供倒计时、官方公告入口、考前提醒和排进日程。

离线数据无需登录可写入任务

怎么用

  1. 打开「考试日历」查看未来考次；勾选“只看官方已确认”可隐藏规则推算的预计日期。
  2. 点“排进日程”为单场考试创建任务和时间块，或点“把最近一场排进日程”一次创建最近一场。
  3. 需要核对信息时点“官方公告”；在任务标题里写“四级”“考研”等关键词后，可使用任务动作关联最近考试。

标为“预计”的日期由历史规律推算，可能整周偏差。报名、缴费和准考证时间要以官方公告为准。

赛

竞赛消息雷达

gx-news

消息

从摩课云竞赛平台获取竞赛通知和资讯，支持关键词、类型和月份筛选，标记已读，并把带时间的消息转为Le时间管理提醒。

需要联网无需登录可自动刷新

怎么用

  1. 打开「竞赛消息雷达」，点“刷新”拉取消息；需要持续关注时开启“每 10 分钟自动刷新”。
  2. 用关键词、类型、月份、“只看未读”等条件缩小范围；点消息卡片会标记已读并打开详情。
  3. 对包含报名或截止时间的消息点“提醒”，Le时间管理会解析日期并创建任务和时间块。

消息来自第三方平台，网络不可达或页面结构变化时会显示抓取错误。报名信息以平台公告原文为准。

课

时光课程表

shiguang-schedule

校园

按周查看课程，支持学期周次、节次、自定义时间、单双周、课程编辑、彩色课程块与个性化配置、JSON 导入导出、ICS 导出，并可把本周课程加入时间块。

需先设学期本地保存支持导入

怎么用

  1. 第一次进入先点“时间与学期”，填写第一周内的开学日期、总周数和每节课的起止时间。
  2. 点“添加课程”填写课程名、教师、地点、星期和周次；周次支持“1-16”“1,3,5”或单双周按钮。
  3. 在“我的 → 个性化配置”里调格子高度、圆角、间距、透明度和显示内容；打开“彩色课程块”后每门课是一块实色卡片，没手动调过色的课按课名自动分配颜色，同一门课始终保持同一色。
  4. 用“备份与恢复”迁移拾光 JSON 或导出 ICS；点“同步到时间块”把本周课程排进Le时间管理日程。

课程冲突会在加入时间块前停止。已经加入的旧时间块不会因为后续修改课程表而自动更新。

学

学习通通知

chaoxing-notify

校园

登录学习通后查看消息中心、待办作业、课程列表和通知分享码详情，支持关键词过滤、打开原文和把通知转为Le时间管理提醒。

需要账号需要联网凭据留本机

怎么用

  1. 打开「学习通通知」，输入手机号或学号、密码并登录；下次进入会优先尝试本机保存的凭据自动登录。
  2. 用关键词搜索消息或课程，点“刷新”更新列表；有分享码时粘贴到通知查询框查看正文。
  3. 对带时间的通知点“提醒”，即可创建任务和时间块；需要查看原文时点“打开”。
  4. 「待办作业」页按提交状态分五档：未截止未提交 / 已逾期未提交 / 已提交未截止 / 已提交已过期 / 已提交待批改。顶部那五格本身就是筛选器，点任意一格只看那一档，再点一次取消；选中的档位记在本机，下次打开还在。第五档收的是通知里没写截止时间、但已探到已提交的近期作业（只列近 60 天发布的），成绩没出之前它不算完。

消息中心接口存在平台 IP 白名单，被拒时课程和分享码查询仍可使用。账号密码会写入本机数据文件，请只在可信设备上使用。

警

警大门户通知

cppu-notify

校园

中国人民警察大学智慧警大门户通知查看工具，支持 SSO 验证码登录、会话续期、月份筛选、正文阅读和转为Le时间管理提醒。左侧「校园服务」栏内置 WebVPN、教育邮箱、教务、学工、一网通办五个入口，默认收起、点左上角把手展开，标题与图标自动识别。

仅限学校用户需要联网密码不保存

怎么用

  1. 打开「警大通知」，输入学号、密码和验证码；看不清验证码时点击图片换一张。
  2. 登录后点“刷新”拉取通知，按月份筛选并展开正文；会话失效时点“重新登录”。
  3. 对带时间的通知点“转为提醒”，Le时间管理会识别日期并创建任务和时间块。
  4. 左侧「校园服务」栏默认收起，点左上角的「校园服务」把手展开，可以进 WebVPN、教育邮箱、教务、学工与一网通办（各类申办事项都在这里），点一下用浏览器打开；侧栏头部的「◂」可以收回。

密码只在本次登录内存中使用，不写入磁盘；门户票据会在应用运行期间保留，退出应用后通常需要重新登录。

微

微信提醒推送

wechat-push

提醒

通过 Server酱把时间块开始提醒推送到微信。可以设置提前 3、5、10 或 15 分钟，并保留推送记录。

需要 SendKey需要联网免费额度受限

怎么用

  1. 打开 sct.ftqq.com，用微信扫码登录，关注服务号并复制 SendKey。
  2. 回到「微信推送」粘贴 SendKey，选择提前时间，先点“发测试消息”确认微信能收到。
  3. 打开“开启推送”。之后时间块开始前会自动发送，页面下方可查看成功或失败记录。

Server酱免费额度每天 5 条，超出后推送会失败。SendKey 会保存在本机，换设备或怀疑泄露时应在服务端重新生成。

More plugins / 第三方插件

还想安装其他插件？

桌面端可以在「设置 → 插件」导入用户插件 ZIP，也可以把插件目录放进数据目录的 plugins/ 后再点“重新扫描”。Android 当前以内置插件为主，外部目录扫描能力请以实际版本为准。
