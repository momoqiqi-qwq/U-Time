# v0.283.2 · 我的体测：加上总分

## 改了什么

只动 `cppu-notify` 插件（插件版本 1.87.1 → 1.87.2）。三端同源，无数据迁移、
无接口变更、无新权限。

**顶部多一格「总分」。** 位置在「项目 / 记录 / 学期」之前，单独配色
（`--sea` 描边 + 同色浅底），数字后面跟等级胶囊：优秀（≥90）/ 良好（≥80）/
及格（≥60）/ 不及格（<60）。

**算法：国家学生体质健康标准（大学组）七项权重。**

| 项目 | 权重 |
|---|---|
| 体重/身高（BMI） | 15% |
| 肺活量 | 15% |
| 50 米 | 20% |
| 坐位体前屈 | 10% |
| 立定跳远 | 10% |
| 引体向上（女：1 分钟仰卧起坐） | 10% |
| 1000 米（女：800 米） | 20% |

权重合计 100%，各项目取**该学期最好一次**的 `fraction`（服务端给的百分制单项分）
乘权重相加 —— 得到的正是学校上报的那个百分制总分。

**为什么是本地算的。** 服务端没有可用的总分来源：

- `POST /iot/h5fitness/fitnessAchievementActivity/getZLScore` 恒返回
  `code=1`「不能展示记录成绩」，带 `termCode` 也一样；
- `selectWeightscore` 直接 500（NPE，缺必填参数）；
- 记录里的 `weightScore` / `allWeightScore` 字段都是空的；
- 学生端 SPA 的 JS 里搜不到任何「总分 / 总评 / 综合得分」文案 —— 原 App 也不给学生看总分。

所以界面上把这行字写明了：「总分按国家学生体质健康标准权重加权（各项目取最好一次）」。
**缺项时不编数**：只把已出的项目算进去，并在同一行注出「还有 N 项没出成绩（xxx、yyy），
未计入」；权重表之外的项目（学校自加项）也会点明「不在标准七项里，也未计入」。
切学期时总分跟着重算。

## 影响范围

纯插件内视图，桌面 / Android / 微信小程序三端一致。

## 验证

`npm test` 全通过；`sync-version.js --check`、`sync-plugins.js --check` 均 ✓。
实机（vite dev + headless Chrome）核对：2025-2026 学年算出 75.4 分 / 及格，
与离线用同一份快照按同一权重算得的 75.37 一致。
