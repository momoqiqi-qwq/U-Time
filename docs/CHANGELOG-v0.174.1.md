# v0.174.1 · 「显示介绍」开关也管得住作者行

## 改了什么

- 「设置 → 插件 → 显示介绍」关掉后，两处插件列表的**作者行**还留在卡片上 ——
  开关只盖住了描述（`.pd` / `.market-card-desc`），没盖住作者行
  （设置页的 `.plug-info .pm`、插件中心的 `.market-card-meta`）。
- 后果就是关掉开关后每张卡片仍显示一行「作者 U-Time内置」；插件中心的 `author` 字段
  有的插件塞的是整段更新记录（「警大门户通知」那条能撑到 7 行），卡片高度全被它顶开，
  「显示介绍」也就失去意义了。
- 现在同一条 off 规则覆盖四个选择器：两处列表的**描述 + 作者行**。默认值本来就是
  「关」，所以升级后插件中心与设置页的插件列表会直接变成
  「图标 + 名称 + 版本徽标 + 操作」的紧凑形态；想看介绍把开关打开即可。
- **版本徽标（`v1.7.1 · 内置`）刻意不动** —— 那是插件身份，不是介绍文案。

## 影响范围与数据迁移

- 只改 `src/styles.css` 一条规则的四个选择器，Windows / Web / Android 三端同时生效
  （插件中心与设置页共用同一份样式）。
- **无数据迁移**，不碰任何存储字段；开关仍是 `uiPreferences.showPluginDescriptions`，
  默认 `false`（即「不显示介绍」）。
- 小程序端不共用这份 CSS，本次未动。

## 验证

- 真机实测（`npm run dev` + 无头浏览器，真宿主）：对 `data-plugin-descriptions` 切 on / off，
  逐个量 `getComputedStyle().display`：

  | 位置 | 元素 | 开 | 关 |
  |---|---|---|---|
  | 设置 · 插件管理 | `.plug-info .pd`（描述） | 18/18 | **0/18** |
  | 设置 · 插件管理 | `.plug-info .pm`（作者行） | 18/18 | **0/18** |
  | 插件中心 | `.market-card-desc`（描述） | 18/18 | **0/18** |
  | 插件中心 | `.market-card-meta`（作者行） | 18/18 | **0/18** |

- 改之前同一测法量到的是：描述 0/18（已生效）、作者行 **18/18**（漏），两处都一样。
- 走**真实 UI 路径**复验：点设置里那个 `.plugin-desc-toggle`，`data-plugin-descriptions`
  由 `off` 翻到 `on`，两处列表的四类文案同步出现；再点回去同步消失，全程零页面错误。
- 回归断言加严：`scripts/test-ui-preferences.mjs` 现在要求那条 off 规则同时含
  四个选择器（原先只要求描述的两个），少任何一个都报红。
- 三端版本一致 v0.174.1（Android `versionCode 17401`），119 个测试脚本全部通过。
