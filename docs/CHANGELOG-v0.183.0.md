## 用户要求原文

> 「U-Time Work 改成 U Time WorkSpace，然后在下面添加一根像上面代码那样画出来的线。效果类似图中这样子。」

参考图里那条线：左右两条带波纹节点的细主线 + 两端尖饰 + 中间上下对称的菱形与四片卷草花饰，
配色是粉紫 → 珊瑚橙的横向渐变；线比它上方的标题窄。

## 一、字标改名，字号跟着降

`src/shell.js` 的品牌区从 `U-Time Work` 换成 **`U Time WorkSpace`**（用户给的写法：
U 与 Time 之间一个空格，WorkSpace 用驼峰）。

名字长了 42%。哥特黑体（UnifrakturCook）字宽比无衬线宽得多，无头 Chrome 实测宽度：

| 文案 | 28px | 20px | 18px |
|---|---|---|---|
| `U-Time Work`（旧） | 158.06px | 113.40px | — |
| `U Time WorkSpace`（新） | **222.64px** | **159.03px** | **143.13px** |

而侧栏能给字标的宽度（真应用里量的，紧凑密度 / 默认 204px 侧栏）：

- 宽屏（≥1101px）：`.brand` 可用宽度 **166px**
- 过渡带（901~1100px，侧栏被压到 176px）：可用宽度 **146px**

所以字号两档都往下调：

- 基础档 `28px → 20px`（实测 159.03px，留 6.97px 余量）
- 过渡带 `22px → 18px`（实测 143.13px，留 2.87px 余量；19px 会溢出 5.06px）

顺带的性质：新字标在 20px 下宽 159.03px，与旧的 28px 字标（158.06px）几乎一样宽 ——
「侧栏被拖到最窄时字标会顶出 padding box」这个既有行为没有被加剧，宽度口径整体保持不变。

## 二、字标下方那条哥特装饰线

新增 `brandRule()`（`src/shell.js` 里的内联 SVG）+ `.brand-rule` 样式（`src/styles.css`）。
`.brand` 的主轴从 `row` 改成 `column`，线就落在字标正下方（间距 2px，左缘与字标对齐）。

- **形状**照参考图：左右两条带波纹折点的细主线、两端尖饰、中间一条竖线 + 菱形 + 四片卷草 +
  两侧小枝，最上面一层极淡的同色柔光。
- **尺寸 viewBox 160×14**，宽度写 `min(100%, 160px)`：与 viewBox 等宽 ⇒ `preserveAspectRatio`
  的 meet 缩放比恒为 1，线不会被横向拉扁（尖头与卷草会走形）；窄侧栏（过渡带 146px）时整体等比缩小。
- **配色只用 CSS 变量**（`--brand-rule-1..4` / `--brand-rule-ink` / `--brand-rule-tip`），
  浅色与深色两套四档**跟字标完全同一组色值** —— 也就是直接继承字标那份算过对比度的预算
  （浅色 ≥3.5:1、深色 ≥4:1；非文字图形元素的下限是 3:1）。测试比对两组四档必须逐一相等。
- **渐变必须 `gradientUnits="userSpaceOnUse"`**：默认的 `objectBoundingBox` 会让左右两条主线
  *各拿一份完整渐变*，画面从中间断开 —— 这条有变异测试守着。
- **柔光只在深色下开**（浅色侧栏是浅底，叠同色光只会发灰）。

## 三、验证（真 CSS + 真视口，不是静态断言）

无头 Chrome 跑真应用（真 `src/styles.css` + 真 DOM），几何探针实测：

| 视口 | 字标 | 可用宽度 | 装饰线 | 越界元素 |
|---|---|---|---|---|
| 1280×900 | 20px / 159.03px | 166px | 160×14，与字标同左缘（x=27），下方间距 2px | 0 |
| 1050×900 | 18px / 143.13px | 146px | 146×12.8（等比缩），同左缘 | 0 |

像素取证（截图上按「与底色众数的通道最大差 > 30」数墨迹）：装饰线那一行确实是画出来的 ——
160px 宽的主线段在同一行里满行铺开（该行 160 个墨迹像素），中间三分之一墨迹最多（那是哥特花饰），
左 / 中 / 右三段的平均色相依次 328° → 345° → 354°（粉紫 → 红 → 橙红，含与深色底混合的抗锯齿偏移），
与字标三段（321° → 344° → 8°）同向。截图：`le-time-management/output/brand/brand-1280-dark.png`
与 `brand-1280-light.png`。

回归守卫 `scripts/test-brand-wordmark.mjs` 扩到 6 组断言（改名文案 / 两档字号 / 装饰线 DOM 与
viewBox / `gradientUnits` / 线宽写法 / 四档色与字标逐档相等 / 柔光只在深色开），
并做了 12 条变异测试：改回旧文案、字号改回 28px 与 19px、去掉装饰线、`gradientUnits` 退回
`objectBoundingBox`、线宽改成 100% 或写死 106px、浅色四档脱钩、浅色下开柔光、深色覆盖改用
`[data-theme="night"]`、品牌区退回横排、SVG 里删掉花饰那一组 —— **12/12 全部被拦下**。
