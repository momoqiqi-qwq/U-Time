# v0.123.0

## 更新内容

- Windows NSIS 安装器默认使用中文界面，并使用 U-Time 图标及独立的开始菜单文件夹；开始菜单同时提供「卸载 U-Time」。
- 即使手动输入安装路径或通过 `/D=` 指定目录，安装器也会把新安装放进该目录下的 `U-Time` 子文件夹；原有安装继续在原路径升级。
- 安装和卸载过程显示实际路径；卸载确认框明确说明不勾选则保留本机应用数据。

## 影响范围

- Windows NSIS EXE 安装器和卸载器。MSI 与 Android 的安装方式不变。

## 数据迁移

- 无。旧版 NSIS 安装目录保持原样，避免自动更新改变路径。
