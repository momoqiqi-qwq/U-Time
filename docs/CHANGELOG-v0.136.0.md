# v0.136.0 · 一卡通工具栏操作与反馈

- 先绑定工具栏事件，再恢复缓存/凭据和加载日均模块；可选初始化失败不阻断按钮。异常有可见提示，重挂页面移除旧事件，离开页面清理网页计时器。
- 新增“统计”入口返回本地流水和日均面板；原“账单”按钮打开官方完整账单页面。首页、账单、充值和账户中心显示在工具栏下方，不再隐藏在长统计列表末尾。
- 同步账单有忙碌文字、按钮禁用和重复点击保护；缺凭据明确提示先登录。受保护页面检查令牌有效期，必要时完成登录后再进入。
- 刷新：本地统计模式重新同步流水；官方网页模式重新导航当前页面。同步完成不再擅自将已打开的网页切回账单。
- 应用内新窗显式调用原生 open_internal，不受普通网页打开偏好影响；入口限定警大插件及 HTTPS 一卡通 campus-card 路径，错误信息不包含凭据 URL。浏览器版注明另开窗口，弹窗失败不再静默。
- 状态提示移到工具栏附近；跨域 iframe 的 load 事件只表示触发载入，不谎报登录成功或网页可用。网络/内嵌限制提供原生窗口备用入口。
- 登录参数使用 URLSearchParams 替换，保留原查询和路由；失效令牌不继续附加到网址。

验证：新增逐按钮行为测试（包含实际工具栏模板、可选初始化抛错、缓存失败、重复点击、页面切换、原生窗口、令牌、取消和清理）。未使用真实用户账号执行充值或账户变更；官方站点、真实网络及原生窗口交互仍需真机验收。
