# v0.272.1 · 剩余学时标签挪到标签行最后

## 改了什么

`le-time-management/public/plugins/cppu-notify/main.js`（插件版本 1.82.0 → 1.82.1）
「警大选课 › 已选课程」卡片上的学时标签（v0.271.0 引入）从「学分之后」移到标签行**最后**，
现在顺序是：课程类型 → 课程班名 → 学分 → 教室 → 本人自选/教务代选 → **剩余 N 学时**。

- 理由：学时是「这门课自己还剩多少」，压在身份标签之后读起来更顺，
  也不会把教室号往右挤、把本来刚好一行的卡片挤成两行。
- 文案与判定完全没变（`剩余 N 学时` / `学时已上完` / 无课次不显示）。

## 回归断言

`scripts/test-cppu.mjs` 加一条顺序断言：
`本人自选</span><span class="jw-tag hours">剩余 2 学时` —— 学时标签必须排在身份标签之后。

## 影响面

纯插件前端文案顺序，不涉及数据口径、缓存结构与接口；桌面 / Android / 小程序同源。
