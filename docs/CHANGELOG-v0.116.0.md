# v0.116.0

## 改动

- 学校通知网站扩展自动适配：在专用 JSON 适配器与通用 DOM 解析之外，新增内嵌 JSON 状态解析，覆盖更多 Nuxt / Next / Vue 等前端渲染公告页。
- 学校通知网站会从页面脚本里识别常见公告 / 消息列表接口候选，并尝试读取通用 JSON 列表，提升公告栏、消息栏空壳页的成功率。
- 轮换值日成员列表支持拖拽调整长期轮换顺序；临时换人时同步把提醒时刻更新到当前时间，并清理当天已提醒标记，避免换人后提醒仍卡在旧时间。

## 影响范围

- Windows / Android：学校通知网站、轮换值日插件。
- 小程序：轮换值日原生页面同步支持成员拖拽排序与换人提醒时间更新。

## 数据迁移

- 无数据结构迁移。学校通知网站继续复用原站点配置与缓存；轮换值日继续复用原成员、提醒、换人记录。
