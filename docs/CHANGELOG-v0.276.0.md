# v0.276.0 · 学习通课程会话自愈、时间轴视图也能点进课件

## 改了什么

只动 `chaoxing-notify` 插件（`le-time-management/public/plugins/chaoxing-notify/main.js`，
插件版本 2.21.0 → 2.22.0），三端同源，无数据迁移、无接口变更。

**① 课程域会话过期时自动重登一次。** 收件箱会话（`state.sid`）和课程域是两套登录态：
收件箱还能用的时候，`mooc1-1.chaoxing.com` 那边可能已经过期，界面就只弹一句
「登录态可能失效」。现在 `loadCourses()` 见到课程域会话失效、且本地存着账号密码时，
静默重登一次再重试课程列表；重登成功会把新的 `sid` 写回，收件箱也一起续上。

**② 重登带 40 秒冷却。** 密码真的错了不能每点一次就登一次（会把账号打到验证码）。
冷却窗口内再失效，直接把错误抛给界面。

**③ 失败文案分流。** 三种情况分开说：没存账号 → 提示去设置页登录；存了但重登失败 →
「自动登录失败，请重新登录」；重登成功但仍拿不到课程 → 报原始错误。

**④ 一张课都没有不算失败。** 本学期无课时返回空列表，界面显示空态，不再报错。

**⑤ 开课时间轴视图的条目也能点。** 学年分组视图的卡片早就能进课件界面，时间轴视图的
`chaoxing-tl-row` 只是 `<div>`，点了没反应 —— 现在是 `role="button" tabindex="0"`
并带 `data-course-files` / `data-key`，点击、Enter、Space 都进同一个课件界面。

## 影响

- 桌面 / Android / 小程序三端插件同源，无数据迁移。
- 课程卡片的额外请求都落在「进课件界面之后」，不加重同步负担。

## 测试

`le-time-management/scripts/test-chaoxing-autologin.mjs`（新增，6 组断言：课程域自愈、
重登冷却、失败文案分流、空课程、时间轴条目可点）。已做变异测试确认断言有效：
去掉冷却判断、去掉时间轴 `data-course-files`，各自都会红。
