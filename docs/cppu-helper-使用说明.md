# cppu-helper（cppu 小助手）使用说明

> 第三方 App 使用说明 · 作者 **ljnljn（梁家诺）** · 版本 **v15.0（build 151）** · 包名 `com.cppu.helper`
> 本页内容由 `cppu-helper-v15.0.apk` 反编译（jadx）逐页核对得到，不是官方文档；
> 本项目（U-Time / Le时间管理）的「警大门户通知」教务模块在成绩页布局与校历取数口径上对齐了它，
> 故在此存档一份可查的使用说明。

## 0. 它是什么

个人开发的**非官方**校园工具，与学校官方无关。把警察大学几个校内系统（教务、一卡通、学工请假、
WebVPN 站点）的数据聚到一个 App 里看，账号密码只用于向学校系统发起登录请求，所有数据只存本机。

App 自己的「关于」原文：

```
作者：ljnljn
版本：v15.0（build 151）

个人开发的非官方工具，与学校官方无关。
账号密码仅用于向学校教务系统发起登录请求，
所有数据只存本机，不含任何埋点或上报。
```

## 1. 首次启动

1. 启动先进入**免责声明页**，页面底部显示版本号 `v15.0（build 151）`。
2. 勾选同意复选框后「同意」按钮才由灰变亮可点；勾选前按钮是禁用状态。
3. 同意状态写入本机 `SharedPreferences`（文件 `cppu_login`，键 `agreed` / `agreedAt` / `agreedBuild`），
   之后不再弹。
4. 同意后自动分流：**已登录 → 主界面**，**未登录 → 登录页**。
5. 在免责声明页按返回键 = 直接退出整个 App。

## 2. 登录

- 三个输入项：**学号 / 密码 / 验证码**，三者缺一不可。
- 密码不是明文提交：先用内置 RSA 公钥加密（`RSA_E=010001`）再放进表单。
- 走学校**统一身份认证**（`sso.cppu.edu.cn`），提交字段为
  `username / password / authcode / rememberMe / execution / _eventId=submit / loginType=1 / encrypted=true`。
- 验证码可点图片刷新。
- 失败提示分三类：
  - 「验证码错误，请点验证码图刷新后重试」
  - 「账号或密码错误」——附提示：检查密码是否区分大小写、有无多余空格；点右侧眼睛可查看已输入的密码
  - 「锁定」——**先停止尝试**，反复重试可能延长锁定时长，等待自动解除；长时间未解除联系学校信息中心或教务处
- 勾选「记住密码」后账号密码存在本机，下次自动填充。
- 断网时可点 **「🔌 离线查看（缓存于 X 分钟前）」** 直接看上次缓存，不登录。

## 3. 主界面

- 顶栏标题：**cppu 小助手**。
- 未登录时顶栏下方有一条离线横幅：**「🔌 离线查看中 · 数据不会更新」**，右侧 **「去登录 ›」**。
- 底栏**默认**五项：课表、校历、成绩、主题、个人信息。
- 「更多」菜单（右上角）八项：
  `📤 导出本周课表` / `📤 导出成绩单`（在成绩页时）/ `🗂 导出整学期课表（每周一张）` /
  `🔑 登录（当前为离线查看）`（离线时才有）/ `🌙 切换深色模式`（深色时显示 `☀️ 切换浅色模式`）/
  `⚙ 设置` / `🔄 检查更新` / `📋 更新日志` / `ℹ️ 关于（ljnljn）`。

### 3.1 全部功能面板

点「全部功能」展开，显示 **共 11 项**，逐项可进入：

| 序号 | 功能 | 说明 |
|---|---|---|
| 1 | 课表 | 教务课表，三视图 |
| 2 | 校历 | 教学周历 |
| 3 | 成绩 | 成绩总览与统计 |
| 4 | 选课 | 选课批次**信息查询**（不代抢） |
| 5 | 一卡通 | 余额、流水、付款码 |
| 6 | 大转盘 | 吃饭随机推荐 |
| 7 | 主题 | 换配色与背景图 |
| 8 | 校园地图 | 楼栋定位与导航 |
| 9 | 校园直通车 | WebVPN 站点入口 |
| 10 | 我的请假 | 学工请假记录 |
| 11 | 个人信息 | 学籍信息 |

### 3.2 底栏设置

面板底部有「底栏设置」卡片，原文：

> 勾选要显示在底栏的功能（顺序即勾选顺序）。新增功能默认不放底栏，需要就自己勾。

- 底栏**至少保留一项**，全取消会提示「底栏至少保留一项」。
- 底栏项多于 8 项时，标题自动切换成短名（转盘 / 直通车 / 请假 / 我的 / 地图 …），避免挤成一团。

## 4. 各功能页用法

### 4.1 课表

- 顶部三个切换：**📅 课表 / 📚 总览 / 📊 面板**。
- 「‹ 上一周」「下一周 ›」翻周；另有「回到当周」，不在学期内时会提示「现在不在学期内，没有『当周』可回」。
- 标题栏显示 `第 N 周 / 共 M 周 · 当周`。
- 「📚 总览」按课程聚合：每门课显示 `N 次`、学分、学时、周次，以及 **「📍 点此在地图上定位」**。
- 「📊 面板」三块：本学期课程（课程门数 / 上课次数 / 教学周数 / 当前第几周）、
  成绩与学分（需先在成绩页加载一次）、本周课程安排。
- 「📤 导出」：导出本周课表图片并调起分享；整学期导出走「更多」菜单，逐周生成图片，
  进度条显示「已导出 w / total 周…」，结束提示「已生成 N 张课表图片」。

### 4.2 校历

按周卡片列出，当前周标「本周」，其余显示 `N 次课`。

### 4.3 成绩

- **总览**：总学分、平均绩点、平均分、最高分、最低分。
  平均分按**学分加权**（与 GPA 同口径），卡片会注明「学校系统多为算术平均」的差异。
- **GPA 走势**：分学期折线。
- **学分进度**：已修学分 / 参考毕业学分（内置 170，标注**仅供参考**）/ 完成度 / 总学时。
- **成绩分布**、**课程构成**（必修 / 选修 / 其他，各带门数、学分、GPA）。
- **分学期列表**：每学期一行 `N 门 · X 学分 · GPA Y`。
- **📤 导出成绩单**：生成不含账号密码的图片，可直接分享或保存；提示「已生成：文件名」。

### 4.4 选课

只做**信息查询**：有哪些批次、什么时候开、自己够不够格、限几年级、还剩多少时间。
页面内明确写着「在线选课 / 抢课功能暂未开放……选课请到学校教务系统或『学习通』等官方渠道完成」。

### 4.5 一卡通

- 首次进入弹**使用前必读**：说明隐私（不上传任何信息）、付款码等同于钱包、风险自担；
  必须点「我已理解并自行承担」才能用，点「暂不使用」则退出该页。
- 卡片信息：姓名 · 卡号、有效期、卡片状态（非「正常」时会红字提示）。
- **账户余额**、**最近交易**（分页，底部「加载更多…」→「没有更多了」）。
- **💳 付款码**：二次确认弹窗 → 生成条码，页面标注「有效期约 N 秒，过期请重新获取」
  和「⚠️ 请勿截图或转发给他人」。
- 页面底部「ℹ️ 关于本页」写明：只读查询余额 / 流水 / 卡片信息，**不含充值、提现、挂失、绑卡**。

### 4.6 大转盘

- 标题「吃饭大转盘」，默认菜单 6 项：水煮肉片、淮南牛肉汤、麦当劳、西餐厅、麻辣烫、烤冷面。
- 「🎲 开始转」→ 结果「就吃：XXX」；转动过程中不能改菜单（提示「转完再改菜单」）。
- 「✏️ 编辑菜单」：每行一个，**至少 2 项、最多 12 项**（超了会提示「扇区太多会看不清」）；
  对话框另有「恢复默认」。结果只存在本机。

### 4.7 主题与背景

- 「主题商店」：**跟随系统** + 8 套主题 —— 公安蓝（默认）、暗夜黑、森野绿、暮云紫、暖阳橙、
  水墨黑白、深海蓝、纯黑省电。
- 每张卡显示色板（底 / 卡 / 栏 / 点）与「✓ 使用中」/「点击使用」；切换即时生效，提示「已切换到「XXX」」。
- 「背景」区：**启用背景图**、**自定义背景图**、**压暗程度（越大文字越清晰）**、
  「选择图片」/「换一张」、「移除背景」。原图删掉不影响（图片已复制到 App 私有目录）。

### 4.8 校园地图

- 底栏按钮：**➕ 加点 / 📍 我的位置 / 🏫 教学楼 / 📋 地点 / 🗺 图层 / ✖ 导航**。
- 图层可切**高德（中文注记）**与 **OpenStreetMap**；某张底图加载不出来会提示切回高德。
- 状态栏提示「长按地图任意位置可添加地点」；长按弹出四项：
  `添加地点 / 把我的位置设在这里 / 导航到这里 / 校正楼栋位置到这里`。
- 「🏫 教学楼」列出 A / B / C / D 区、1 号教学楼（纯数字教室）、研究生教学楼、7 号楼，
  点一项即定位；「关于教学楼坐标」说明映射规则：纯数字教室 → 1 号教学楼；A/B/C/D → 综合教学楼各区；E → 研究生教学楼。
- 「📍 我的位置」用系统定位（提示来源 GPS / 网络定位与精度），失败时可长按地图手动设置。
- 「✖ 导航」给出步行估算：`到「X」步行约 N 米 · 方位（点地图可清除）`。
- 「📋 地点」可重命名、删除、全部清除；内置地点删除后重新进入可能被自动补回。

### 4.9 校园直通车（WebVPN）

- 首页分区：**WebVPN 主页**（「🔐 打开 WebVPN（首次需登录）」）、**校内系统**、**我的链接**、**校外资源**。
- 内置 15 个校内站点：学工系统、教学资源一体化平台、警大云盘、网上办公系统、智慧财务系统、
  科研创新服务平台、研究生教育管理系统、本科教育门户、本科教育质量评估系统、国有资产管理平台、
  智慧教室综合平台、教学管理指挥系统、数据警务技术专业教学平台、专业信息资源中心、计算机考试系统。
- 校外资源内置中国知网。
- 站点首次点击会自动用 App 里保存的账号尝试登录统一身份认证；
  **验证码必须人工输入**，会提示「账号密码已自动填好，请输入验证码」。
  自动登录失败会弹窗说明常见原因（认证密码与 App 里保存的不一致、账号被限制登录），并建议在
  「设置」里关掉「保存账号密码」。
- 网页工具条：**🏠 主页 / ◀ 后退 / ▶ 前进 / 🖥 桌面版网站（或 📱 切回手机版）**。
- 「＋ 添加链接」可自定义名称 + 网址（如「图书馆」「jw.cppu.edu.cn」），支持删除。
- 在该页按返回键两次才退出（第一次提示「再按一次返回退出」）。

### 4.10 我的请假

- **需要先登录 WebVPN**，否则整页显示「需要先登录 WebVPN」+「🔐 登录 WebVPN」按钮。
- 统计卡：**进行中 / 已销假 / 被拒绝** + 共 N 条记录；离线时标注「⏱ 数据来自缓存（X 分钟前）」。
- 列表每条显示时间区间、事由、时长、状态；「＋ 发起请假」与「撤销申请」都会跳到网页表单完成
  （原因为 ASP.NET 网页表单，App 内不直接提交）。
- 常见报错文案：
  - 「学工系统没有放行这个账号（统一身份认证已经通过了，是学工业务这一层没开权限）」
    → 重复登录不会有变化，需联系辅导员或学工部门开通权限
  - 「还没登录 WebVPN（或登录已过期）」/「登录已过期，请点『＋』重新登录 WebVPN 后再试」

### 4.11 个人信息

展示教务侧的学籍信息（对应缓存 `K_PROFILE`）。

| 小部件 | 内容 |

## 6. 设置

分区：**我的信息 / 外观 / 本地数据 / 关于**。

- **外观**：深色模式开关（「跟随系统时无需设置；手动切换后会一直用所选外观」，右侧显示当前为「深色」/「浅色」）。
- **本地数据**三项清理，每项都有二次确认：
  - `🧹 清除本机保存的账号密码` —— 不影响已缓存的课表、成绩等离线数据
  - `🖼 清除导出的图片` —— 显示当前张数与占用大小，删除后无法恢复但可重新导出
  - `🗑 清除离线缓存（课表/成绩/信息）` —— 不影响账号密码与已导出图片
- 底部说明：**「🔒 账号密码与所有缓存只保存在本机，不会上传到任何服务器。」**
- 「关于」卡：作者 ljnljn、版本 v15.0（build 151）、说明「个人开发的非官方工具，数据以学校教务系统为准」、
  以及缓存时间（如「课表 3 分钟前 · 个人信息 1 小时前」）。

## 7. 检查更新

「更多 → 🔄 检查更新」：已最新则提示「已是最新版本 v15.0」；
有新版本弹窗显示当前版本 / 最新版本 / 【更新内容】（作者未填写时显示「（作者未填写更新日志）」）/
【下载地址】+ 提取码，点「立即更新」跳浏览器到网盘页，点「稍后再说」跳过。
「📋 更新日志」可在 App 内滚动阅读（Markdown 渲染）。

## 8. 数据与隐私

- 所有凭据与缓存只写本机 `SharedPreferences`（文件 `cppu_login`）与 App 私有目录，
  不含埋点、不上报第三方。
- 会访问的学校域名：`jw.cppu.edu.cn`（教务）、`sso.cppu.edu.cn` / `sso-jw.cppu.edu.cn`（统一身份认证）、
  `yktcard.cppu.edu.cn`（一卡通）、`webvpn.cppu.edu.cn`（WebVPN）、`xg.cppu.edu.cn`（学工）。
- 导出的成绩单 / 课表图片保存在本机，**最多保留最近 12 张**。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 「网络好像没连上（解析不了学校服务器地址）」 | 检查 Wi-Fi 或流量后重试 |
| 「连接学校服务器超时」 | 不在校园网内时，先连校园网或学校 VPN |
| 「连不上学校服务器，可能正在维护」 | 稍后重试 |
| 登录提示「锁定」 | 停止重试，等自动解除；长期未解除联系信息中心 / 教务处 |
| 一卡通「学号或一卡通密码错误」 | 一卡通密码与统一身份认证密码不是同一个 |
| 请假页提示未登录 WebVPN | 点「🔐 登录 WebVPN」登录一次后回来刷新 |
| 地图定位失败 / 未授权定位 | 长按地图「把我的位置设在这里」手动设置 |
| 课表教室定位不到楼栋 | 提示「「XXX」暂未匹配到楼栋」，可在「🏫 教学楼 → 校正楼栋位置到这里」修正 |
| 深色主题下卡片发白 | App 内部有对比度自检日志 `CppuContrast`，属于已知的卡片背景未主题化告警 |
