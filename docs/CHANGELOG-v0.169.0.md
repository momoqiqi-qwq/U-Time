# v0.169.0 · 番茄玻璃材质实验室

## 改了什么

- 开启「番茄计时卡液态玻璃」后，计时卡内出现可用鼠标、触摸或方向键移动的玻璃片；拖动范围限制在卡片内，位置随界面偏好保存。
- 新增液态玻璃、柔焦玻璃和圆角切片三种材质。材质选择使用应用已有的滑动选中光。
- 新增折射强度、边缘高光、圆角大小、散射模糊和流动幅度五项参数及重置按钮。参数随界面偏好保存，不改计时状态。
- 柔焦与圆角切片静态绘制；液态玻璃在允许动效时继续流动。页面隐藏、关闭效果或离开插件时沿用 GPU 暂停和释放机制。

## 影响范围与数据迁移

- Windows/Web/Android 共用前端效果。微信小程序维持原生计时器。
- 无数据迁移；现有用户首次升级时获得默认材质和参数，液态玻璃开关仍为默认关闭。
