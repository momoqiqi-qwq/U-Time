# v0.272.4 · 学分页的课程卡片认三种状态

## 改了什么

`le-time-management/public/plugins/cppu-notify/main.js`（插件版本 1.82.3 → 1.82.4）

「我的学分」展开后的课程卡片原来只有两态：已获得 / 未获得。而教务只回一个
`SFHDXF`（是否获得学分），一门**还在修、成绩没出**的课 `SFHDXF` 自然也不是 `1`，
于是被画成红边框 + `未获得学分` 红标签 —— 学生一眼看过去像是自己挂了。

现在按「有没有成绩」再分一层：

| 状态 | 判据 | 标签 | 边框 |
|---|---|---|---|
| 已获得 | `SFHDXF === "1"` | `已获得学分`（ok） | 卡片淡出（`.done`） |
| 未获得 | 有 `ZPCJ` 且未获学分 | `未获得学分`（live） | 红（`.fail`） |
| 在修未出分 | 没有 `ZPCJ` | `在修 · 未出分`（muted） | 常规（`.doing`，走 `--line-soft`） |

`SFHDXF` 的判定口径（`jwGradeDone`）一处未动，学分合计、模块分组、隐藏已修完都不受影响 ——
只改卡片的外观与那句话。

## 回归断言

`scripts/test-cppu.mjs` 新增三条：塞一门没有 `ZPCJ` 的课进去，必须出现 `在修 · 未出分`、
同一张卡片里不得出现 `未获得学分`、类名必须是 `jw-credit-course doing`（不打红框）。
原有两条（已获得 / 未获得同时出现、隐藏已修完只留未获得的课）继续绿 —— 测试 fixture 里
没修完的三门课都带真分数，所以仍按「未获得」渲染。

## 视觉验证

`dev/shot-cppu-credit.mjs`（新增，不进测试套件）把 `jwAcademicCreditHtml()` 渲成静态页，
模块行读真抓包 `jw_credit_raw.json`，再用无头 Chrome 截图核对。顺带记一条坑：
成绩行**必须**带 `SFHDXF: "1"`，否则整页学分全是 0 —— 「已获得」不看分数。

教务没给的口径一概不猜。
