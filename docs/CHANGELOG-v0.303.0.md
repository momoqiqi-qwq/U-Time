# v0.303.0

- 轮换值日新增「周六周日同一人」开关（桌面插件「轮换规则」与小程序的设置区各一个）。开启后周日不推进轮换，周六与周日由同一个人当班，周一接着轮到下一位，不跳过任何人；关闭时行为与之前完全一致。
- 开启后抬头会标出「周六周日同一人」，「接下来的轮次」在周六那行补一句「周日同人」——周日不再单独占一行，免得看着像没人值日。
- 轮换数学：周日按「不占槽位的日子」处理（与暂停日同类），所以周期为 7 天时本轮在日历上会多含一个周日；结束日按「下一槽位首日 - 1 天」计算，落在假期里则退回假期前一天。序号反解改为二分并跳过暂停日，跨多年假期也能一次算准。
- 数据：组上新增 `weekendSame`（布尔，默认 `false`）。缺字段的旧数据与旧备份一律按关闭处理，脏字符串不当成开启；桌面与小程序备份可往返，无数据迁移。
- 覆盖三端：桌面插件、小程序页面与小程序核心纯函数；新增周末合并、暂停与周日重叠不双扣、开关渲染与跨端一致性测试。
