# v0.135.0 · 一卡通日均餐费

- 新增独立日均统计面板，可切换餐饮消费 / 全部消费；不改变原有充值、消费汇总和账单同步。
- 同时显示消费日均（除以出现该类消费的日期数）和日历日均（除以所选周期日历天数，当前周期只算到今天）。
- 可按年、月、周、学年选择历史周期，支持上一期 / 下一期和回到当前；周一至周日，学年默认每年 09-01 起，可修改为其他每年有效的 MM-DD。
- 金额按分累加、显示两位小数，正确处理闰年、跨年周、未来周期、无数据和重复日期。
- 餐费依据商户和摘要关键词识别；关键词可修改。明确商超/洗浴等优先排除；未识别记录单独显示，不冒充餐费。支出口径不冲抵退款，也不包含其他支付渠道。
- 显示同步时间、历史数据不完整风险和抓取/缓存上限提醒；无记录显示空态，不能认定每天花费为零。
- 设置保存在本机插件普通偏好中，不涉及账号密码；日期、分类、计算及 UI 逻辑放在独立按需加载模块 card-averages.js，避免继续扩张门户主文件。

验证范围：本地模拟流水与设置交互回归；不使用用户真实账单或账号执行测试。真实商户字段及餐饮识别效果仍需用户对照账单核实。
