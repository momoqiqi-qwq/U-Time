# v0.174.0 · 星图可以关掉床铺线框了

## 改了什么

- 「轮换值日」的星图工具栏多了一个 **「显示床铺」开关**：关掉之后只剩星星与连线，
  床架（铺板 + 立柱）整体隐藏 —— 就是 `动画演示/宿舍床位星图-3D/` 原型稿那个观感。
  默认**开着**（与之前一致），拨一下即时生效、跨轮换共用、落盘保存。
- 实现上用 `display:none` 一条规则隐藏，而不是「关掉就不生成元素」：原地重画
  （`roomDraw()`）那条路因此不用分叉，不会出现「转视角转到一半元素没了」的中间态。
- **开关不动几何**：`roomBounds()` 永远把铺板与立柱算进取景范围，所以拨开关时星星
  一个像素都不挪（测试里逐点比对了投影坐标）。观感开关让画面跳位置是最容易被当成 bug 的。
- 顺带把整块星图的顶部注释补齐：为什么**不画地板与墙**（按整间房取景会把一半画面让给
  地板和空气，实测星距从 57px 掉到 21px），以及两个开关各自的语义。

## 顺手修掉一个版本号脱节（我上一轮自己埋的）

- 上一轮 0.172.1 → 0.173.1 时，我改 `package-lock.json` 用的是**字符串替换**——
  JavaScript 的 `String.replace(字符串, …)` 只命中第一处，于是顶层 `version` 变成了新值，
  而 `packages[""].version` **留在 0.172.1**，两份字段各说各话。这正是仓库根 AGENTS.md
  专门警告过的那个坑（「实测曾停在 0.11.2 而 package.json 已到 0.11.6」）。
- 已改回一致，并新增 **`scripts/test-version-consistency.mjs`** 把它钉死：校验
  `package.json` 是严格三段式、`package-lock.json` 的**顶层与 `packages[""]` 两处**
  都对得上、`Cargo.toml` / `tauri.conf.json` / 小程序 `appMeta.js` 跟上、
  Android `versionName` 一致且 `versionCode` 等于 `major*10000+minor*100+patch`。
  `gen/android` 不存在（新克隆的树）时跳过 Android 两条并**明确打印跳过**，不假装验过。
- 反向验证：只把 `packages[""].version` 改回 0.172.1，该测试立刻报红并指名道姓。

## 影响范围与数据迁移

- 只改插件本体与插件使用说明，Windows / Android 同时生效。
- 存储键 `roomView` 多一个 `beds` 字段（布尔）。**只有显式 `false` 才算关**，
  缺省 / 老数据 / 脏值一律按「画」处理 —— 升级后观感与上一版完全一致，无需迁移。
- 小程序端不画这张图，本次未动。
- 插件清单版本 1.9.0 → 1.10.0（`tools/sync-plugins.js` 已同步两端 catalog）。

## 验证

- 单测新增一组：默认画 / 显式关掉 / `beds: 0` 与缺省都按画处理 / 勾选框的 `checked`
  状态 / 容器 `data-room-beds` 属性 / **开关前后逐点比对投影坐标完全相同** /
  CSS 隐藏规则与事件绑定都在。
