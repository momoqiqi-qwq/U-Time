# v0.154.0 · 动效节奏优化

- 借鉴 NepheleWorkshop 的 ViewWrapper、NepheleButton、NepheleDialog：页面入场加入轻微纵向位移和缩放，320ms 内完成；弹窗用轻回弹配合独立淡入，避免透明度随弹性曲线波动。
- 按钮按下采用 80ms、0.97 倍缩放，释放以 220ms 轻回弹归位；移出按钮后释放也能恢复，连续操作从当前视觉位置接续。
- 弹层退场统一缩短为 180ms，保留入场中关闭时的连续性、动画结束清理及超时兜底。
- 影响 Windows / Android 共用前端；小程序仅同步版本。保留应用和系统的减少动效偏好、拖拽禁用动效、插件首绘宽限期及异步更新仅淡入规则。
- 无数据迁移。
