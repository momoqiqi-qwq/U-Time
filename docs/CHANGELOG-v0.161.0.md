# v0.161.0

## 改动内容

- 桌面端新增“小窗 · 720 × 620”启动窗口预设。
- 自定义启动窗口尺寸下限对齐 Tauri 运行时最小值 `400 × 560`，允许把桌面端收成临时工具面板。
- 新增桌面窄窗口布局层：`901px ~ 1100px` 宽度下压缩侧栏、顶栏、四象限和插件中心间距，避免小窗口中顶栏工具与内容区互相挤压。
- 新增低高度桌面布局层：高度不超过 `680px` 时收短顶栏、侧栏导航行高与核心页面间距。

## 影响范围

- Windows / 桌面端窗口尺寸设置与主界面布局。
- Android 与小程序没有行为变化；版本号按三端同步规则更新。

## 数据迁移

- 无数据迁移。
