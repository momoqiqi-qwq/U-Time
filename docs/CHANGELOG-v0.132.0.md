# v0.132.0

- 插件中心启停不再通过导航通知切换同一页面，也不再延迟重建整个列表，避免双重闪烁。
- 保留原卡片、搜索框和筛选按钮节点；只更新状态、开关语义、打开按钮和插件视图入口。
- 停用/启用使用约 220ms 的轻柔明暗过渡，状态文字使用 180ms 小幅过渡，不播放整页闪光。
- 切换中避免重复请求，以实际插件状态同步结果；失败显示提示，不静默显示成功。
- 保留 Android 多视图入口；筛选成员变化继续使用 FLIP 重排，提供焦点落点。
- 遵循减少动效偏好；普通启停不再重复弹出成功 toast。

影响桌面/Android 共用插件中心；无数据迁移。小程序仅同步版本。
