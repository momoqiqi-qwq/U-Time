# v0.283.0 · 我的体测：图标、容器、染色、学期

## 改了什么

只动 `cppu-notify` 插件（插件版本 1.86.0 → 1.87.0）。三端同源，无数据迁移、
无接口变更、无新权限。

**① 图标换成服务端原图。** 以前是自绘内联 SVG（近似图形），现在是
`projectIcon` 的原始 PNG（96×96，彩色实心圆底 + 白色图形），内嵌进
`fitness-icons.js` 作为 data URL 随插件走 —— 和 App 里那七个圆逐像素一致，
离线、oss 被拦、企业微信 token 过期时都照原样显示。运行时若还能抓到更新的
`projectIcon`（`state.icons` 缓存），那条优先，后端换图能跟上。

**② 七项装进一个容器。** `.fit-list` 从「每项一枚卡片」变成一枚外层卡片
（边框 + 圆角 + `overflow:hidden`），项与项之间只留 1px 分隔线；
`grid-template-rows` 0fr ⇄ 1fr 的双向展开/收起动画与 `inert` 焦点隔离不变。

**③ 成绩染色。** 每项挂 `--fit-c`（该项目图标圆内的主色，从 PNG 采样：
体重/身高 `#58A0F0`、肺活量 `#F09878`、坐位体前屈 `#8050C8`、立定跳远
`#F8B840`、引体向上 `#50C0B8`）。右侧数字、单位后的分数、展开区每次记录的
分数、进度条全部取这个色，并用 `color-mix` 混 14%（数字）/ 38%（次要文字）
的 `--ink` —— 浅色主题下 ink 是深色、等于压暗提对比，深色主题下 ink 是浅色、
等于提亮，一套写法两种模式都可读。

**④ 学期可切换。** 顶部胶囊单选，光块由宿主 `tide.ui.selectionGlow` 画
（铁律六）。只有一个学期时只显示那一枚（不当开关用），两个以上才多出「全部」；
选择记进 `fitnessViewPreferences.term`，重进页面恢复。

**一处如实复刻，不是 bug：** 服务端把 `50米` / `1000米` 的 `projectIcon`
都指向 `肺活量.png`（原 App 表现如此），所以这三项同图同色。后端换图标后
重跑 `fitness-icons.js` 的生成步骤即可。
