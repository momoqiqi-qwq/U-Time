# v0.290.1 · 插件缓存失败恢复与重载一致性

## 修复

- 修复缓存文件写入失败后，重启读取旧文件并删除最新回退值的问题；失败的删除也会保存待恢复标记，避免旧缓存重新出现。
- 同一插件重载后共用缓存状态与同键写入顺序，防止旧实例迟到的写入覆盖新值，同时保留并发冷读去重。
- 恢复失败写入前优先采用明确的待恢复值；后端仍不可用时保留该值和标记，成功恢复后才清理。未标记的历史 `storage` 数据继续按原规则迁移。
- 导入或替换数据后按当前存储命名空间获取状态；旧异步操作只能清理原命名空间，不能删改导入后的值。

## 范围与数据兼容

- 影响 Windows / Android 共用插件宿主；浏览器调试模式继续直接使用插件存储，小程序仅同步应用版本。
- `plugins.<id>.cachePending` 为宿主记录失败写入的可选元数据，不占用插件 `storage` 的合法键；任务、时间块与数据格式版本不变，无需手工迁移。
- 新标记保护升级后发生的失败写入；历史未标记的回退值与普通旧迁移值无法自动区分。
- 三端版本 `0.290.0 → 0.290.1`，未构建或发布原生安装包。
