# CHANGELOG · v0.110.0

## 手机端交互闭环（路线图第一版）

### 新增：悬浮键可设置（设置 → 外观）
- **悬浮键高度**：偏低 35% / 居中 45%（默认，v0.52.1 实测遮挡最少）/ 偏高 55%。
  实现为垂直锚点变量 `--fab-v`，‹ 返回与 ⋮ 菜单两颗键同步生效；
  守卫断言同步锚定默认值（test-chrome-toggle）。
- **悬浮键左右互换**：开关打开后 ‹ 在右、⋮ 在左（`data-fab-swap`），适合左手习惯；
  两侧安全区（横屏挖孔）双路取值照旧，互换只是交换、不丢让位。

### 新增：边缘手势返回
- 从**屏幕左缘 28px 内**起滑的横滑 = 返回上一页，**插件页内也生效** ——
  补上 v0.108 把插件页中部横滑让给插件（课表切周）后丢失的滑动返回。
- 只认「从左往右拉」（与 Android 系统返回同向）；页面中部横滑行为不变；
  既有守卫保持：偏好开关、拖拽会话让路、56px 阈值、横纵向比例。

### 新增：课表作息模板（课程表插件 v3.12.0）
- 「时间与学期」页节次编辑器新增**「套用模板」**：大学 10 节 / 中学 8 节 / 晚课 4 节
  一键铺进文本框，可逐行手改，「保存设置」才落库 —— 与「按间隔生成」互补
  （模板给起点、生成器给自由度）。

### 影响范围
- `src/uiPreferences.js`（fabHeight / fabSwap）、`src/views/settings/appearance.js`（两行设置）、
  `src/styles.css`（`--fab-v` 档位 + 互换规则）、`src/shell.js`（边缘手势带）、
  `public/plugins/shiguang-schedule/`（模板，manifest 3.12.0，`main.js` 已重建）。
- 新偏好有默认值与归一化兜底，老存档无感升级；无数据迁移。
