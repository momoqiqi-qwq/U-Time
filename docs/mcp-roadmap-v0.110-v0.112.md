# 更新路线图 · v0.110 → v0.112（功能优先版）

> 2026-09-27 规划，经确认：功能优先、验收压轴。依据：近三轮全是手机端主题、

> 每版遵循铁律：升版本三步、四项 --check、npm test、CHANGELOG；Win/Android 构建串行。

## v0.110.0 —— 手机端交互闭环（三项全做）✅ 已发布（2026-09-27，81/81 测试通过）

1. **悬浮键可设置**（外观页）：高度档位 35% / 45% / 55% + 左右互换。
   实现：CSS 写死的 `top: calc(45% - 18px)` / `left/right` 换成 `--fab-v` / `--fab-side`
   变量，uiPreferences 加两项 + data-* 消费（照抄 0.108 navDock/navGlass 模式）。
2. **边缘手势返回**：屏幕左缘 ~28px 内起滑的横滑 = 返回上一页（含插件页）；
   页面中部横滑继续归插件（课表切周不受影响）。补上 0.108 后插件页失去滑动返回的缺口。
   守卫：既有手势测试 + 新增边缘起滑断言。
3. **课表作息模板**：节次生成器旁加「套用模板」（大学标准 10 节 / 中学 8 节 / 晚课型），
   一键填 textarea，保存才生效 —— 与自由生成器互补。

风险：中（边缘手势有误触面）。验证：npm test + 手势专项场景自查。
