# v0.138.0 — 任务状态操作优化

- 单任务删除撤销使用时间块 ID 集合去重，将恢复时的嵌套扫描改为线性扫描；保留 ID 冲突时的现有记录，重复撤销不重复恢复。
- 删除任务时一次扫描收集受影响日期并移除关联时间块；修改任务标题时直接更新关联记录，减少临时数组。
- 象限显示、同象限拖拽和跨象限拖拽共用排序规则，保持完成态 → 手工顺序 → 截止日期的语义与稳定排序；移除拖拽过程中的重复 order 回填。
- 增加大批量单任务撤销回归，覆盖扫描次数、时间块 ID 冲突、日期缓存、通知次数、重复撤销和持久化。

影响桌面与 Android 共用前端；小程序仅同步应用版本。无需数据迁移。
