# v0.173.0 · 轮换值日新增 3D 宿舍床位星图

## 改了什么

- 「轮换值日」插件多了一张卡片：**宿舍床位 · 值日星图**。按 4 / 6 / 8 人间（或关闭）选择，
  把上下铺画成天上的星：星星上是成员名字，星上的圆数字是他在名单里的位次，
  一条流动的实线按 1→x 串起值日顺序，尾端虚线绕回第 1 位。今天当班的那颗亮成绿色
  （每轮多人就当班几颗），跟成员列表里的绿色描边同源。
- **实心星 = 上铺、空心星 = 下铺**，颜色统一。同一张铺的两颗星沿铺宽略微错开
  （图中标注了「示意错开」），所以俯视时也分得开。
- 相机可绕房间转：**立体 / 俯视 / 正视**三个机位，鼠标或手指拖动转视角、滚轮缩放，
  另有「自动旋转」开关（默认开，可关，减少动效时自动不转）。视角与开关跨轮换共用、落盘保存。
- 舞台**刻意不引 three.js**：场景不过十几颗星加几十条线，自己写球形轨道相机 + 透视投影，
  星星是绝对定位的 DOM（CSS 3D 的透视会把名字和数字一起压扁发虚），铺板与立柱是 SVG。
  体积为零，文字清晰。
- 点一颗星会跳到它在「成员 · 轮换顺序」里的那一行并闪一下（拖动过之后的补发点击不算）。
- 星空底：`data-nephele-background="on"` 时卡片让成透光薄层，把整幅星图交给 nephele 星空背景；
  关掉则退回普通卡片。窄屏（≤ 720px）自动换成竖版取景框，星距实测 1.8 倍。

## 影响范围与数据迁移

- 只改插件本体（`public/plugins/dorm-duty/`）与插件使用说明，Windows / Android 同时生效。
- 新增一个**每组**字段 `roomSize`（0 / 4 / 6 / 8，缺省 4）与插件级存储键 `roomView`
  （机位、角度、缩放、自动旋转）。两者都是可选字段：老数据没有就走默认值，不需要迁移，
  旧版本客户端读到新数据也不会崩。
- 小程序端同语义实现里补了 `roomSize` 的默认值与归一化（与桌面端同一个集合与默认档），
  否则「手机上复制整套轮换」会把宿舍人数悄悄重置；小程序不画这张图。
- 插件清单版本 1.8.0 → 1.9.0（`tools/sync-plugins.js` 已同步桌面与小程序 catalog）。

## 验证

- 几何真跑（`scripts/test-dorm-duty.mjs` 新增一组用例）：4/6/8 人 → 2/3/4 张上下铺、
  贴左右两面墙、每张先下铺后上铺；三个机位下投影不出 NaN、不越框、
  任意两颗星在 854px 宽卡片上间距 ≥ 34px、近大远小压幅在 0.86~1。
- 浏览器实测（临时自检页，真跑 `ensureStyle()` + `roomHtml()`）：
  宽屏 1020px 与窄屏 430 / 380 / 360px 各三档机位，**名字两两不重叠、不压到别的星星、
  不被卡片切掉**，连线端点与星心偏差 < 0.8px（1px 边框的取整误差）。
- 反向验证：把「名字脱流」改回留在文档流里，连线端点立刻偏离星心 9px（已修，注释写明了原因）；
  把默认方位角调回正对房间对角线，两个对角铺位会叠到 10px（已在 `ROOM_VIEWS` 注释与测试里钉住）。
- 三端版本一致 v0.173.0（Android `versionCode 17300`），118 个测试脚本全部通过。
