# v0.242.1

## 改了什么

警大校历（`cppu-notify` 插件 · `cppu-calendar` 视图）的图标从「六边形立体底板 + 白色图形」改成**纯线条图形：线内着色、线外全透明**。

- 删掉六边形底板、rim 描边、顶部白高光、偏移模糊投影 —— 那块底板本身就是一块彩色填充，等于给图标又套了一层背景色。
- 六个图形改为 `stroke="currentColor"`，实心小块也走 `currentColor`，颜色只有一处来源；输出 SVG 除线条外不含任何填充。
- 六色重取「白卡与深紫卡上都够看」的中间调：对 `#FFF` ≥3:1、对 `#232029` ≥4.6:1，因此不再需要按 `data-theme-mode` 出两套色板。
- 图形整体放大 1.3 倍（学期起止的双向箭头本身扁，单独 1.55）；线宽同步降一档（6 / 7 / 8.4）补偿放大带来的视觉加重。

## 影响哪端

仅 Windows / Android 桌面壳与 App 内的「警大校历」视图，以及微信小程序同源插件包。图标生成器 `public/plugins/cppu-notify/cal-icons.js` 的对外签名不变（`calIcon(key, size)`，六个键 `cal` / `term` / `week` / `course` / `event` / `sync`），调用方一处未改。

## 数据迁移

无。校历数据（学期、个人事项）的存储键与结构不变。

## 版本

- 应用：`0.242.0` → `0.242.1`
- 插件 `cppu-notify`：`1.60.0` → `1.60.1`
