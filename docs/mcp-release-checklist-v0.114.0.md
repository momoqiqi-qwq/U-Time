# 真机回归清单 · v0.114.0

> 验收重点：应用内网页右侧工具箱可见、刷新始终可用，且不拦截网页正常交互。
> 自动化测试和打包不能替代实体设备验收。

## Windows 桌面端

- [ ] 在设置中启用「应用内打开网页」，打开普通站点；确认右侧工具栏出现且第一颗按钮为「刷新网页」。
- [ ] 点击刷新、后退、前进，确认只作用于当前内置网页窗口。
- [ ] 收藏当前网页、打开收藏列表、跳转并移除收藏；站点 A 与站点 B 的收藏不互相泄漏。
- [ ] 复制网页地址、缩小和放大网页；缩放不超过 75%–150%，关闭或重开网页窗口无异常。
- [ ] 打开一个有 iframe 的页面，确认只显示一条工具栏；页面按钮 / 链接 / 输入框仍可正常操作。

## Android 实体设备

- [ ] 普通网页与学习通带登录态网页都出现侧边工具栏；刷新后仍留在当前应用内窗口。
- [ ] 点按刷新、后退、前进、收藏、复制链接、缩放；触控不误触网页内容或系统手势。
- [ ] 打开 / 关闭收藏面板并点页面空白处收起；系统返回键仍可关闭网页窗口。
- [ ] 若使用模拟器，只记录为模拟器冒烟，不替代实体设备验收。
