# v0.272.0 · 警大新增「我的考试」视图

## 改了什么

`le-time-management/public/plugins/cppu-notify/`（插件版本 1.81.0 → 1.82.0）

1. **新视图 `cppu-exam`「警大考试」**，挂在侧栏「教务」子菜单里（学生请假之后），
   标题 `警大考试`、菜单路径 `学生服务 › 我的考试 › 我的考试计划`、图标 `clock`。
   只读：缓考 / 免考申请仍在教务里提交。
2. **两条教务功能码**（`JW_FUNC` 新增，`funcId` 来自浏览器真机抓包，不是猜的）：
   - `examPlan` → `V_JWBZK_KWGL_KS_STU`（`sql` 型，`funcId 8doEdJCt9B3MRujeyKo`）：考试计划，
     一个学期可能多条（秋季 / 春季各一条）。
   - `examTask` → `V_JWBZK_KWGL_KSRW_STU`（`func` 型，`funcId XyTHnkGDVnGOCTQECC6`）：具体安排，
     必须带 `KS`（计划 ID）+ `XNXQ`（学期码）+ `XH like %学号%` 三个条件才只回自己的。
3. **取数顺序**：先读考试计划定学期 → 按 `jwTermOrder` 降序挑「当前学期，没有就最近一个学期」
   → 该学期每条计划各打一次安排接口 → 按 `ID` 去重、按开考时间升序。
   一条计划的安排失败不影响其它计划；**全部**失败才报错并删掉半成品缓存。
4. **视图内容**：
   - 顶部三格统计：共几场 / 距下一场（今天 / 明天 / N 天后 / 已结束）/ 首末场日期跨度。
   - 学期胶囊（只有多条计划时才出现），选中光随选择滑动。
   - 待考组（含「进行中」）按时间正序在前，已结束组收在后面并整体调暗，下一场左侧挂一条红标。
   - 每场一张卡：日期块（月 / 日 / 周几）、课程名、时段、考场、主考 / 监考。
   - 当前学期还没排考时，自动回退到最近一个学期并在顶部明写「教务还没排考…已经考完了」，
     不把「还没排」装作「没有」。
5. **搜索**（铁律十）：课程名 / 课程号 / 考场 / 主考 / 监考 / 日期 / 时段都能搜，
   同时认原文、拼音首字母（`gs` → 高等数学）与跳字简写（`wt` ⊂ `wct`）。
   多个词取**交集**，但每个词只在**单个字段**内比 —— 不 join 成整串，
   否则「张三 李四」拼起来会让 `sl` 假命中跨人组合。空结果写明支持哪些输入。
6. **缓存**：落进 `jwSaveCache` 的 `keep.exam`（与其它教务数据同一条通道），
   重进视图先用缓存上屏、后台再刷；形状不对（无 `plans` / `terms` 不是对象）一律当没缓存。

## 数据口径（实测）

- 计划级字段：`ID / KSMC / XNXQ / KSKSZC / KSJSZC / KSSJ / KSKSSJ / KSJSSJ / ZT`。
- 安排级字段：`ID / XNXQ / KCMC / KCBH / KSDD / KSSJQJ / ZKXM / JKXM / XH / ZT`。
- 时段字符串形如 `2026-01-15 08:00-09:50`，正则同时容忍 `~`、`–`、`至` 三种分隔符
  与不补零的写法（`2026-1-5 9:00`），解析不了就原样显示原文。
- **没有座位号字段**：`KCHJ` 实测恒为 `01`、语义不明，不硬编成「座位号」。
- 2026-10-20 实测当前学期 `20262027-1` 还没有考试计划，接口只回 `20252026-1`（2 条计划 / 4 场）
  与 `20252026-2`（7 场）—— 这就是上面那条「回退 + 明说已结束」的由来。
