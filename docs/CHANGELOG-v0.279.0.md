# v0.279.0 · 隐私展示模式补第五条：姓名 / 学院这类纯文字身份字段也要糊

> 起因是房主拿真实截图验收：模式开着，屏幕上「张三 · 汉族 · 示例学院 · 示例专业」
> 一个字都没糊。前四条规则一条都碰不到它 —— 没有数字（①②③ 空转）、不含校名（④ 空转）。

## 一、为什么是「加一条」而不是「扩一条」

原四条规则都靠**内容特征**命中：

| 规则 | 命中依据 | 对「防火工程学院」 |
|---|---|---|
| ① 人脸 | `[data-private-face]` 打标 | 不适用 |
| ② 数字 9 化 | 文本里有数字 | 没有数字，空转 |
| ③ 三维图全满 | `[data-private-full]` 打标 | 不适用 |
| ④ 校名模糊 | 命中校名列表（警大 / CPPU / 全称…） | 不是校名，空转 |

要扩 ②，就得把「汉族 / 女生 / 某学院 / 某专业」这些词硬编码进去 —— 而宿主根本
**分不清「防火工程学院」是身份字段还是业务数据**（同样五个字可能出现在公告标题里）。
所以第五条只能反过来：**插件知道自己渲染的是什么，由插件打标，宿主只负责糊**。

## 二、新规则 ⑤ 身份文字模糊

```js
// 插件侧：谁知道自己画的是身份字段，谁打标
el("h2", { "data-private-text": "" }, "张三");
```

```css
/* src/styles/privacy-mask.css —— 唯一消费方 */
:root[data-privacy-mask="on"] [data-private-text] {
  filter: blur(5px);
  user-select: none;          /* 拖选能拿到原文 = 白糊 */
  -webkit-user-select: none;
}
```

三个刻意的决定：

1. **只糊不换字**。`filter: blur()` 不改 `textContent`，关掉模式立刻还原，
   也不改宽度断行 —— 与 ④ 校名同一套思路，和 ② 的「改字符」明确分开。
2. **扫描器必须把 `[data-private-text]` 当跳过区**（`privacyMask.js` 的 `EXEMPT_SELECTOR`
   并进 `SKIP_SELECTORS` 那条路径）。否则会把已经糊掉的那块再做 9 化，
   关掉模式还原出来的是 9 化后的值 —— **等于把数据改坏**。
3. **`user-select: none` 是规则的一部分**，不是锦上添花。糊着却能拖选复制，
   等于什么也没做。

## 三、打标落在哪（4 个插件）

| 插件 | 位置 | 打标对象 |
|---|---|---|
| `cppu-notify/profile.js` | 个人信息页 | 姓名（`<h2>`）、民族 / 学院 / 专业 / 班级等字段值、头像（`data-private-face`） |
| `cppu-notify/growth.js` | 成长记录页 | 姓名 |
| `cppu-notify/award-list.js` | 获奖名单 | 每条姓名 + 队名（一屏几十个真名） |
| `dorm-duty/main.js` | 宿舍值日 | 床位人名牌（宿舍号 + 真人名最容易被认出来）、当班人、候选 chip、本周安排里的人名 |

## 四、设置页与徽标

- 设置卡新增第五行说明「身份字段模糊」，讲清它跟前四条的区别（没有数字也不含校名）。
- 顶栏徽标 tooltip 改为「人脸模糊、数字 9 化、三维图全满、校名模糊、身份字段模糊」，
  开关 toast 同步。

## 五、边界（这一版**没有**处理，也不是这一版该处理的）

- **`title=` / `aria-label=` 属性里的真名**：悬浮提示与读屏仍会念出原文。属性不是文本节点，
  要糊得改成「遮罩 + 自定义 tooltip」，是另一件事。
- **剪贴板**：`profile.js` 复制姓名得到的仍是原值 —— 剪贴板不属于「屏幕显示」。
- **登录表单里的账号**：表单区（`FORM_SELECTOR`）整棵跳过，属「输入中」不属「展示数据」。
- **插件之外的新页面**：谁画身份字段谁打标，宿主测不到「这里漏了一个真名」。
  测试只能守已知的 4 处锚点（`test-privacy-mask.mjs`）。

## 影响面

- 三端全量：桌面 / Android / 小程序都吃同一份 `privacy-mask.css` 与插件代码。
- **无数据迁移**：只加了一个属性选择器与若干空值标记，不动存储结构、不改渲染流程。
- 关掉模式后行为与 v0.278.0 完全一致（`filter` 与 `user-select` 随 `data-privacy-mask="off"` 一起失效）。
