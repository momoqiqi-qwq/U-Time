# CHANGELOG · v0.107.0

## 课程表插件（shiguang-schedule）v3.11.0

### 新增
- 「时间与学期」设置页新增**课的时间间隔生成器**：填「开始时间 / 每节时长 / 课间时长 / 节数」，
  一键生成全部节次行并写入下方文本框，可再逐行手改；点「保存设置」才落库（与手改同一条
  normalize 校验路径）。生成器会自动拦下越过 23:59 的组合并给出可读报错。

### 修复（安卓）
- 修复「时间与学期」等子页滚动后**标题穿进状态栏**的问题：Android edge-to-edge 的状态栏
  是透明浮层，宿主垫的顶部安全区 padding 拦不住滚动；现在子页头部（‹ 返回 + 标题）滚动时
  sticky 钉在安全区下方（复用宿主同一条 `(2px + --sat) ÷ --ui-scale` 公式），并垫半透明
  毛玻璃底，滚动行从标题底下过，不再从状态栏底下过。
- 修复**周视图工具栏（‹ 第N周 › ⋯）滚动后钉进状态栏**的问题：sticky 的约束矩形是
  scrollport（含 padding 区），插件里 `top:0` 的吸顶栏滚起来会一直顶到状态栏底下；
  现在由宿主统一钉到 `--safe-top-anchor`（内容起始线）上。
- 新增**滚动保护带**（`.view::before`）：一条状态栏高度的 sticky 毛玻璃，未滚动时
  恰好铺满顶部 padding 空档、不占布局空间，滚动时钉在 scrollport 顶 —— **全部插件页**
  （AI 对话、RSS、通知类等）与核心页的内容滚进顶部时都从带底下过，而不是从状态栏
  底下过。纯视觉层（pointer-events:none），桌面（>900px）不生效。
- 修复**悬浮键（‹ 返回 / ⋮ 菜单）遮挡节次文本框**的问题：窄屏给高 textarea（节次表 /
  教务文本）两侧留出 44px 走廊，首行文字与左右缘不再被玻璃圆钮盖住、可正常点选。
- 节次文本框加 `rows=10` 与 `spellcheck=false`：一屏能看清全部节次，输入不再飘红色波浪线。

### 影响范围
- 仅桌面端与安卓端的课程表插件（`public/plugins/shiguang-schedule/`，manifest 3.10.1 → 3.11.0，
  生成物 `main.js` 重新构建）；微信小程序版为原生实现，不受影响。
- 无数据迁移：节次表数据结构与存储格式不变。
