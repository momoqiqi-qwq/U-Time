# v0.133.0 · 警大校历、校园网站与登录重试

## 校历
- 摘要显示学期教学结束日（起始日 + 教学周数 × 7 − 1），明确标注推算，不能当作学校放假日期。
- 今天所在教学周使用红色下边框/颜色标记，独立于选中的日期；学期外不伪装成最后一周。
- 读取课程表插件当前课表，按本周周一至周日统计课次和总节数，处理单双周；自定义时间课计课次，未知节数单独说明。
- 无课表/插件关闭/超时不冒充零课次；课表与校历学期起始不同会提醒核对。数据仅只读查询，不导出课程明细或凭据。

## 独立 WebVPN / 警大网站插件
- 新增独立插件及专属切换界面；门户侧栏跳转至该插件。
- Windows / Android 显式使用既有应用内网页窗口展示官方 WebVPN 登录与资源目录、警大官网，不依赖普通链接打开偏好。
- 登录及后续资源访问均由官方网页处理；不是自建密码表单或门户 Cookie 注入。插件不读取密码和会话，不用 iframe，也不绕过 CSP。
- Web 调试版会打开独立浏览器窗口，并明确提示环境差别；打开失败显示错误，不假报已登录。
- 小程序不支持此插件；目录和图标通过原有同步工具生成。

## 门户登录
- 手动按钮和密码自动登录使用同一重试控制器，默认失败后重试 2 次（最多 3 次尝试）。
- 可在警大侧栏「登录设置」或登录表单中的「登录设置」改为 0–5 次；0 关闭额外重试。
- 每次自动尝试使用新会话、execution 和验证码，并进行 0.8/1.6/3.2/4 秒退避；防重复提交，离开手动登录页停止后续尝试。
- 密码错误、账号锁定、429/请求过频和其他明确不可重试响应不继续提交。最终失败准备新的人工表单，避免复用失效 execution。
- HTTP 500 提示仅说明可能原因，不把会话失效当作已确诊的服务端根因。WebVPN 官方登录不受本设置控制。

## 验证边界
新增本地回归测试覆盖计数、日期边界、红色当前周、超时、重试上限/取消/互斥/凭据错误以及校园窗口路由。
官方未登录 WebVPN 入口已实测可达并进入代理认证页；未使用用户账号执行真实登录，未完成 Windows / Android 真机登录和视觉验收，也未打包安装程序。
