# v0.272.2 · 考试卡可以点开

## 改了什么

`le-time-management/public/plugins/cppu-notify/main.js`（插件版本 1.82.1 → 1.82.2）

「警大考试」（`cppu-exam` 视图）的每张卡片现在是可展开的：

- **收起态**只留扫一眼就要的四样：日期块（几号 / 月 · 周几）、课程名、时段、考场与状态标签。
- **展开区**放主考、监考、课程编号、完整日期（含年份）、教务原文时间 —— 这些平时查不占地方，
  但一学期十几场全部平铺会把列表拉成一屏两场。
- 展开 / 收起走 `grid-template-rows: 0fr ⇄ 1fr` + 不透明度 + 箭头翻转的**双向**过渡，
  内容收起时留在 DOM 里继续插值（`display:none` 会跳高度、也做不出收起动画）；
  `prefers-reduced-motion: reduce` 下立即到位。
- 整张卡是 `role="button"` + `tabindex="0"`，点击、空格、回车都能开关，`aria-expanded` 同步。
- 开着的卡按**考试 ID**记在 `jwState.examOpen`，过滤重绘、切学期再切回来仍然开着。
- 搜索命中「只在展开区」的词（主考 / 监考 / 课程号 / 完整日期 / 原文）时，那张卡自动摊开 ——
  否则等于给了一张搜到了却看不见命中词的卡。命中 `课程名 / 考场 / 时段` 这类收起态就可见的字段时不强制摊开。
- 「教务原文」改为**只在和解析结果逐字不同**时才显示（教务写成跨天、带「至」之类时留作对照），
  正常行不再重复一遍日期与时段。
- 窄屏（≤600px）展开区固定两列，长值不再折成竖排。

## 回归断言

`scripts/test-cppu-exam.mjs` 新增：

- 源码结构：`grid-template-rows:0fr` 的折叠容器、`.open` 回到 `1fr`、箭头 `rotate(180deg)`、
  减少动效选择器里带上 `.jw-exam-fold` 与 `.jw-exam-chev`。
- 渲染：卡片带 `role="button" tabindex="0" aria-expanded="false"`、折叠区结构、监考进展开区、
  收起态不再摆主考监考、无残留 `jw-exam-sep`。
- 行为（vm + 卡片替身）：点击摊开 / 再点收起都要同时动 `class`、`aria-expanded` 与
  `jwState.examOpen`；搜 `李老师`（只在展开区）必自动摊开，搜 `大学计算机`（收起态可见）不许强摊开。
- 原文对照：正常行 `doesNotMatch /<b>教务原文<\/b>/`；跨天的怪格式必须出现且占满一行。
