# v0.149.0

## 数据可靠性（Windows / Android 共用前端，浏览器调试）

- 读取失败、损坏快照或未来 schema 停在恢复页，不启动业务界面、插件与自动化，不允许空状态覆盖原文件。
- 恢复页支持重试读取、验证备份后确认恢复；原生恢复前保留原始文件副本，浏览器恢复前保留原始存储值。
- 保存队列独立为 `persistence.js`：串行提交独立快照，区分待保存、保存中、已保存和失败；提供重试与导出未保存数据。
- 原生主数据写入同步临时文件后替换，Unix 同步目录，并串行化读写/恢复。
- 浏览器主键改为 `letime-data`，兼容读取 `tidebalance-data`，不删除旧数据。

## 刷新与结构

- 四象限复用未变化的任务卡，跳过无关刷新；筛选计数未变化时保留按钮。
- 时间线按键复用未变化节点；保留排序、展开状态与视图滚动位置。
- 设置按分类创建卡片，搜索覆盖分类元数据及设置正文；局部重绘，关闭时释放导航/更新监听，恢复备份后使旧设置卡失效。
- 拆出设置提醒、数据中心、快捷键与局域网模块，导航拖拽模块，原生存储与凭据模块。
- 小程序插件业务拆为报告、考试、值日、消息收纳模块，值日页面控制器独立，公开接口保持兼容。
- 独立特性布局样式，保留主题令牌事实源与原有 CSS 顺序。
- 小程序静态检查统一入口；保留并接入原有 260 项核心断言，修正过期插件数量，同时继续运行现有 51 项核心断言与 27 组控制器回归；更新模块拆分后的源码断言。

## 数据兼容

- 无业务 schema 升级，无任务/时间块/插件备份格式变化。
- 仅浏览器存储键随成功保存写入新键，旧键保留。
- 不改变既有插件 `tide` API，也不修改小程序后台能力边界。
