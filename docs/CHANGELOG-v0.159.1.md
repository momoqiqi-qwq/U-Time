# v0.159.1 · 收窄 Windows 默认启动窗口

## 改动

- Windows 桌面端默认启动窗口改为中等尺寸 `1360 × 860`，避免在大屏上打开得过大。
- 「设置 → 界面与交互 → 启动窗口大小」保留预设、最大化和自定义尺寸；自定义宽高仍可在 `900 × 600` 到 `3840 × 2400` 间调节。
- 「跟随屏幕」模式继续按显示器可用区域计算，但在大屏上封顶到 `1440 × 900`，避免已有自动模式偏好接近满屏。

## 影响范围

- Windows / Linux 桌面端启动窗口尺寸。
- Android 与小程序不受影响；窗口尺寸设置仍只在桌面安装版显示。

## 数据迁移

- 无数据迁移。
- 已经手动选择过「宽大」「铺满可用区域」或自定义尺寸的用户，现有偏好保持不变。
