# CHANGELOG · v0.115.0

## 轮换名单随日期置顶今日当班人员

- 「成员 · 轮换顺序」名单按当前日期对应的排班动态展示：今日当班者排在第 1 位，多人当班按当班顺序一起置顶；临时换人时置顶实际替班人员。
- 这只是展示排序，不会改写长期轮换名单、起始日、周期或历史排班；↑↓仍然编辑长期轮换顺序。轮换尚未开始时保留原名单顺序。
- Windows / Android 共用插件与微信小程序原生视图同步此行为；应用内页停留跨过换人日时会自动刷新置顶顺序。

## 影响范围与迁移

- 影响 U-Time 桌面端、Android 与微信小程序的「轮换值日」插件。
- 无数据结构迁移；不改动现有成员排序或换人记录。
