# v0.139.0 — 任务与排程自定义

- 新增「任务与排程」设置分区：默认任务象限、默认预估时长（15～1440 分钟，支持整数自定义）、默认截止时刻、新任务默认开启提醒、自动排程起始时间、空白时间块默认时长和默认分类。
- 四象限快速添加支持自定义默认时长；空白时间块的按钮和回车使用同一份默认值。
- 显式选择与捕获解析结果优先于默认值；已有任务不回写、不批量修改，截止时刻仅在任务有截止日期后参与提醒。
- 自动排程可从凌晨开始；日时间轴自动扩展以显示提前的排程和已有凌晨时间块，避免排程落在不可见区域。
- 新设置支持全局搜索直达、独立恢复默认和备份随行；非法导入值自动归一化。

影响桌面与 Android 共用前端；时间块页选项主要用于桌面。小程序同步版本并保留备份设置，本次不增加其设置入口。无需数据迁移。
