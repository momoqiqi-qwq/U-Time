# v0.297.0

## 自习室首页：按课表定位楼层

- 自习室页顶部新增「今天去哪」卡片：读教务课次（学生课表综合查询）里这一天还没上完的第一节课，取它的地点，得到要去的楼与楼层。
- 卡片直接列出这层在此刻（或所选日期那节课的节次）空闲的教室号与间数，最多列 12 间，多的折成「+N」。
- 「看这层全部教室」等价于点一下楼胶囊 + 节次胶囊，并把那栋楼的卡片滚进视野，下面的全楼清单仍是原来那一套筛选。
- 今天的课已上完时取当天最后一节并标注「今天的课已结束」；今天没课则向后找 7 天内最近的排课并说明是哪天；看明天 / 后天 / 自定义日期时按那天第一节课定位。
- 课表未拉取、拉取失败、这天一周内都没排课、这层没返回教室，各有明确文案，不补数。
- 这层有教室但这一节全被占时不只给一个 0：补一句「换节次或往下看别的楼」，把下一步说出来。
- 提示与免责文字用 `--ink-2`（深色下 5.9:1，AA 达标）；`--ink-3` 只保证 3:1，小字不用它。卡片边在深色下抬到 42% mint，否则近黑底上没有轮廓。
- 节次落到哪一节按作息时间推算（1 节 08:00-08:45、课间 10 分钟，与课表插件默认节次一致），卡片上写明「节次按作息推算」——自习室接口只有日期与节次码，没有钟点。

## 影响范围与数据

- Windows / Android 插件界面同一份代码，微信小程序侧不涉及该视图。
- 自习室视图的取数由 `["room"]` 变为 `["room", "qjCourse"]`：进页面会多拉一次整学期课次（与选课、请假视图同一份），课次仍不落盘。
- 楼 / 楼层 / 节次的筛选口径与原来一致，无数据迁移。

## 验证

- 新增 `jwRoomFloorOf` / `jwRoomClockSlot` / `jwRoomFocus` / `jwRoomPlanHtml`，无状态副作用；楼名沿用 `jwRoomBuilding`，与全楼清单同一套归类。
- 按仓库要求执行版本三端同步、主题、课表生成物、Android 原生一致性四项校验与全量测试。
