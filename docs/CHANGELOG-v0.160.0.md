# v0.160.0

## Nephele 风格扩展到全应用

- 「设置 → 界面与交互 → Nephele 风格设置界面」更名为 **「Nephele 风格界面」**，作用域从**仅设置弹窗**扩展到**全应用**：核心视图（任务表 / 时间线 / 时间块 / 收件箱 / 插件中心）、全部内置插件页、左侧导航栏、顶栏、卡片、抽屉、命令面板与设置弹窗一起换外观。
- 实现方式：这套紫调令牌（`--bg` / `--paper` / `--panel` / `--ink*` / `--line*` / `--deep` 等）从原来只挂在 `.settings-modal / .set-wrap` 上**提升到 `:root`**，于是所有靠 `var()` 取色的组件一次性跟随；再补一层外壳与卡片的毛玻璃、圆角与紫色描边。
- 外观要点：侧栏与主区在桌面端变成**半透明毛玻璃**（背景开启云雾时能透出底下的云），顶栏与卡片同步半透明；侧栏选中图标的强调色由主题色换成紫色 `--deep`；设置弹窗的底色由不透明 lavender 改成半透明玻璃（原来那条 `backdrop-filter` 挂在不透明底上，等于空转）。
- 两个开关仍**互相独立**：「Nephele 云雾与星尘背景」管动态背景，「Nephele 风格界面」管配色与材质；只开风格不开背景时，界面是一套实色紫调，观感同样成立。
- 低端设备逃生口沿用既有约定：设置里的「底栏材质」选**实色**时，外壳退化为不透明板并关掉实时模糊（实时模糊是低端 WebView 滚动掉帧的大头）。
- 性能取舍：模糊只加在**外壳那两块大板**上，列表卡片只做半透明、不各带一层 `backdrop-filter` —— 云雾是 12.5s / 17.5s 的常驻动画，背景每帧都在变，几十个列表项逐项模糊会持续重算合成层。
- 补 `test-nephele-settings` 源码守卫（令牌必须在 `:root` 上、外壳与表面清单必须被覆盖、卡片块不许带 `backdrop-filter`、设置页紫色下划线与 solid 逃生口必须保留），三条变异均能被判红；另用真浏览器探针逐项量 used value 验证全应用生效。

## 同版并入：收窄 Windows 默认启动窗口（原编号 v0.159.1）

- Windows 桌面端默认启动窗口改为中等尺寸 `1360 × 860`，避免在大屏上打开得过大。
- 「设置 → 界面与交互 → 启动窗口大小」保留预设、最大化和自定义尺寸；自定义宽高仍可在 `900 × 600` 到 `3840 × 2400` 间调节。
- 「跟随屏幕」模式继续按显示器可用区域计算，但在大屏上封顶到 `1440 × 900`。
- 该改动原计划单独发 `v0.159.1`，与本次风格扩面同处一个未提交工作树 ⇒ 合并进 `v0.160.0` 一并发布，不单独造号。

## 影响范围

- Windows / Android 前端的整体外观；小程序未添加此风格，不受影响。
- 插件侧：使用宿主令牌（`--panel` / `--line` / `--card` 等）的插件自动跟随；插件自己写死颜色的部分不变（那是插件自己的外观）。

## 数据迁移

- 无数据迁移。偏好键仍是 `settings.ui.nepheleSettings`（只改了显示名，改键要做迁移，不值当）。
- 已经打开过这个开关的用户，升级后会直接看到全应用生效的新外观 —— 这是本次改动的预期行为。
