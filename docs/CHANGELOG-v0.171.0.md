# v0.171.0 · 设置搜索直达具体选项

## 改了什么

- 设置页左栏的搜索框不再只筛「分类」。输入关键词后，搜索框下方会列出命中的**具体设置项**（例如输入「字」能直接看到「文字大小」「字体着色」），点一行就跳到那个控件上，并把落点高亮约 2 秒。
- 结果行右侧标出它属于哪个分区（「界面与交互」「关键词标注」…），一次最多列 12 条；标题命中优先，其次是拼音首字母缩写（「wzdx」也能落到「文字大小」），最后才看关键词。
- 搜索框里支持键盘：↑ / ↓ 在结果间移动，Enter 直达选中项，Esc 清空搜索词。
- 索引复用全局搜索（Ctrl+K）那份设置项清单，两处不会再各写一份、各自漂移。索引未收录的分区（警大登录设置、测试）按分区名兜底，14 个分区都找得到。
- 定位范围收在目标分区自己的节点内：以前用整页查找，别的分区里先出现的同文控件会抢走匹配，而它在桌面是隐藏的（滚不动、也看不到高亮），表现就是「点了没反应」。

## 影响范围与数据迁移

- Windows/Web/Android 共用同一套设置页，三端同时生效。窄屏（≤980px）分类列表被手风琴取代，搜索结果区是搜索唯一的出口，不会被一起收起。
- 无数据迁移；不改任何存储字段，搜索状态只在设置弹窗打开期间保留。
