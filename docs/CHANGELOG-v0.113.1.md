# CHANGELOG · v0.113.1

## 启动过渡与控件交互

- Tauri 窗口启动时先隐藏，恢复用户设置的窗口大小后再显示；避免默认尺寸先露出、随后突然放大的跳变。
- 首屏 shell 完成后加入短淡入，避免白屏 / 闪屏感；尊重应用与系统的「减少动态效果」设置。
- 按钮按压与释放反馈减轻回弹幅度；滑杆统一轨道、已选进度、拇指悬停/按下状态，保留原生拖动与键盘操作。

## 影响范围与迁移

- 影响 Tauri 桌面端与 Android 启动呈现；滑杆和按钮动效为跨端样式调整。
- 无数据结构或用户设置迁移。
- 实机启动观感仍需在 Windows 与 Android 设备上人工复核；自动化 / 构建验证不替代真机验收。
