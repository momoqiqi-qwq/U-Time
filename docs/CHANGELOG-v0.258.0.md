# v0.258.0 · 上网记录：熬夜卡精简、统计范围放到整个学期、逐夜列表可收起

## 改了什么

- `le-time-management/public/plugins/cppu-notify/netlog.js`（只动熬夜卡与其取数，概览/图表/明细的口径未变）
  - **卡面文案精简**：原来卡头挂着一整段口径说明（「同一夜多条记录先合并去重……」），
    把「熬夜」两个字挤到几乎看不见。现在卡头一行只留 **学期 · 阈值**（如「冬学期 · 22:00 后」），
    那段解释原封不动挪到 `<span class="nlog-sub" title="…">` 里，鼠标悬停仍可读 —— 口径不能因为
    「字太多」就丢掉，它决定了数字怎么算。
    主体的四个事实压成一行（大数字 + `累计 · N 夜`，右侧 `平均 / 最晚下线 / 熬夜率`），
    逐夜条最多列 `NIGHT_SHOW = 12` 夜，超出时底部补一句
    「只列最近 12 夜 · 本学期共 N 夜有记录」（`.nlog-night-note`）。
  - **统计范围从「当前区间」改成「整个学期」**：这是本版最实质的改动。熬夜本来就该按学期看，
    而原来的数据源是工具栏那个 7/30/60 天区间 —— 选近 7 天时「熬夜率」只有 7 夜的分母，
    换个区间数字就变，没有可比性。
    服务端单次最多 60 天（`MAX_SPAN`），一个学期约 5 个月，所以 `loadNight()` 按 `semChunks()`
    分片并发拉取（每片 ≤ 60 天，最多 12 片），首屏不等它，拿到后 `paint()` 重画一次。
    - 学期首日按校历节奏估：**春季 2-10 起、冬季 8-25 起**（1 月仍属上一年开始的冬季学期），
      终点固定取今天 —— 未来日期拉了也是空。
    - 一片都没成功（比如登录过期）时**不清空**已有结果，避免网络抖一下把卡面清成「本学期还没有记录」。
    - 阈值仍按**每一夜自己的日期**取（`semOfDay()`），不是按今天取一次：60 天窗口跨过学期边界时，
      2 月里的那一夜该用 22:20，而不是被今天的 22:00 一刀切。校历同步过就优先用学期名
      （`currentSem()` 认「春 / 冬 / 秋」），没同步按月份兜底。
  - **逐夜列表可整块收起**：卡头右侧加一个「收起 / 展开」按钮（`data-nlog-nightfold`，
    `aria-expanded` / `aria-controls="nlog-night-body"` 齐备），默认展开。
    折叠容器复用明细那套 `.nlog-dwrap` + `grid-template-rows: 0fr ↔ 1fr` 的过渡，
    **收与展都有中间帧**（铁律七），收起时给容器设 `inert`，里面的条不能继续被 tab 到。
    状态写进 `netLogViewPreferences.nightOpen`，下次进来还是你上次的样子。
  - **深色模式再抬一档**：熬夜卡的小字（`累计 · N 夜`、平均 / 最晚 / 熬夜率、逐夜时长、底部注释）
    在暗底上实测「能读但不轻松」，按 `--ink` 混到 84–88%（走 `[data-theme-mode="dark"]`，
    不是某个主题名）；底部注释同时把字号从 11px 提到 11.5px 并给独立类 `.nlog-night-note`。

- `le-time-management/scripts/test-cppu-netlog.mjs`（新增断言，接在原有熬夜口径断言之后）
  - 精确：卡面不再出现「口径：」，但 `挂机整夜不会算成几十小时` 必须还在（在 title 里）。
  - 折叠：`data-nlog-nightfold`、`aria-controls` 指向 `nlog-night-body`、默认带 `open` 类。
  - 学期范围：取数请求里必须出现 `start = 学期首日（2-10 / 8-25）` 的那一片、**每片 ≤ 60 天**、
    **end 不得晚于今天**（防止顺手把未来也拉了）。

## 影响哪端

- 桌面端与 Android：同一份 `public/plugins/cppu-notify/netlog.js`，行为一致。
- 熬夜卡首次进入会多打 3–5 个 `logs` 请求（一片 60 天），并发发；首屏不等它。
  请求失败只是这块退回用当前区间的行来算（`nightHtml()` 里的 `state.nightRows` 兜底），不弹错。

## 数据迁移

无。新增的存储字段只有 `netLogViewPreferences.nightOpen`（布尔，缺省 `true`），
读取处按类型兜底，旧偏好文件里没有这一项也照常跑。
