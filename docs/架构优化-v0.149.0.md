# v0.149.0 代码结构与优化验收

本轮按数据可靠性、刷新路径、模块维护三个阶段实施。保留原生 DOM、Tauri 和小程序独立运行栈，不改变业务数据 schema。

## 模块边界

| 层 | 当前职责与入口 |
|---|---|
| 启动 | `src/main.js` 成功读取后启动业务；失败进入 `views/startupRecovery.js` |
| 状态与保存 | `store.js` 维护业务状态；`persistence.js` 维护串行提交与独立保存状态；`views/storageStatus.js` 展示回执、重试、未保存数据导出 |
| 视图更新 | `keyedNodes.js` 根据稳定键及内容签名保留节点；四象限/时间线消费它，不影响全局状态广播与插件契约 |
| 设置 | `views/settings.js` 注册分类、协调懒加载；`settings/navigator.js` 负责分类/搜索/页面导航；提醒、数据、快捷键、局域网分别在对应模块 |
| 外壳 | `shell.js` 继续负责界面编排；纵向插件导航拖拽在 `pluginListDrag.js`，横向工具拖拽在已有 `toolbarDrag.js` |
| 原生 | `lib.rs` 注册命令；主数据读写/恢复在 `storage.rs`，AI/插件凭据在 `vault.rs`；命令名称保持兼容 |
| 小程序 | `core/pluginRuntime.js` 保持旧入口，转发 `core/plugins/` 下的报告、考试、值日、消息收纳模块；值日页面方法在 `pages/plugin/dormDuty.js` |
| 样式 | `styles.css` 保留主题令牌及基础样式；`feature-layouts.css` 保留原尾部布局规则；`storage-status.css` 处理保存状态和恢复页；派生主题仍由生成器维护 |
| 检查入口 | 根 `tools/check-miniprogram.js` 转发到小程序静态检查；保留根目录 260 项核心断言，修正过期插件数量，并将它与小程序目录下的 51 项核心断言、27 组控制器回归一同纳入 `npm test` |

## 故障边界

- 无浏览器快照才返回首次启动的空状态；损坏 JSON、`null`、错误数组结构、读权限错误及未来 schema 不降级为种子数据。
- 恢复前必须保留原始副本；保留副本失败时中止恢复。原生副本位于应用数据目录，名为 `data.before-recovery-<时间戳>.json`。
- 保存失败保留内存数据，允许重试与导出；状态通知不会触发业务刷新或自动化。
- 每次提交克隆写入时的状态；旧快照完成时，如果后来又有更改，状态仍为待保存。
- 现有退出等待上限仍为 2 秒。本轮不声称能保证任意长的磁盘故障或断电都不丢数据。
- SHA-256 校验沿用更新模块现有实现：仅在提供 digest 时启用，不等于独立签名验证。

## 验证入口

```powershell
cd le-time-management
node scripts/test-persistence-recovery.mjs
node scripts/test-keyed-nodes.mjs
node ../tools/sync-version.js --check
node ../tools/gen-theme-dark.js --check
node ../tools/build-schedule-plugin.js --check
node ../tools/sync-android-native.js --check

npm run build
cd src-tauri
cargo test --lib --offline
```

浏览器验收脚本位于 `le-time-management/scripts/verify-optimization-ui.js`，可用 Playwright CLI 的 `run-code --filename` 运行；默认本机测试地址为 `http://127.0.0.1:1422`。它使用浏览器测试上下文，不应在用户已有数据的浏览器会话运行。覆盖分类懒加载、全部设置页、正文搜索、节点复用、保存失败与重试、窄屏布局、损坏数据保护页。

Android 原生通知、安装、WebView 真机安全区以及真实教务登录未纳入本轮浏览器验收。Windows Rust 单元测试不能替代 Android 编译与真机运行。
