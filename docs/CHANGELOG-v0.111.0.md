# CHANGELOG · v0.111.0

## 数据可靠性地基（路线图第二版）

### 新增：数据体检（设置 → 数据中心）
- 一键扫描四类数据问题：**孤儿时间块**（引用的任务已不存在）、**重复 id**
  （互相覆盖、撤销串位）、**超期 NEW 标记**（超 30 天）、**非法日期时间块**
  （含 2024-02-31 这类「格式对但日子不存在」的）。
- **一键修复**，原则保守：重复条目重编号保留数据（时间块引用重定向到首个）、
  超期 NEW 摘标记、孤儿块与非法日期块删除；**修复前自动创建恢复点**，
  与导入/恢复共用同一条安全网，随时可回退。
- 实现为纯函数核心（`src/dataHealth.js` 的 analyze / repairPlan）：不改入参、
  不做 IO，行为面由新测试 `test-data-health.mjs` 全覆盖
  （检出四类、修复后再扫为零问题、入参不可变）。

### 增强：恢复点列表显示快照大小
- 每条自动备份行现在显示占用（KB），删除旧快照前心里有数。

### 诚实备注
- 规划时判断「备份中心缺恢复体验」，实施前复查发现列表/恢复（恢复前自动快照）/
  删除/频率/保留数早已齐备 —— 本版实际增量收敛为数据体检 + 大小显示，
  未重复造轮子。

### 影响范围
- `src/dataHealth.js`（新）、`src/views/settings.js`（体检段 + 备份行大小）、
  `scripts/test-data-health.mjs`（新，82 个测试脚本 +1）。
- 无数据迁移；体检只读，修复需用户确认且先建恢复点。
