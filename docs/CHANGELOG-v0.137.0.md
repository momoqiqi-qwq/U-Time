# v0.137.0 — GitHub 文档交互优化

- GitHub 文档插件升级至 1.3.0。桌面与 Android 共用插件前端，小程序仍不开放该插件。
- 原生 prompt 改为主题化页内编辑面板，统一修改显示名称、备注和图标；留空恢复默认、保存/取消、Esc 与输入法友好的键盘保存。
- 卡片提供直接编辑入口和独立原生阅读按钮，显示别名时仍保留 owner/repo；保留右键/长按快捷入口。
- 移除前确认，仅影响本地追踪和缓存，不操作 GitHub 仓库；保存失败保留草稿，落盘成功才更新展示。
- 修正手动同步提前设置忙碌锁导致请求被跳过的问题；添加和同步防重复，显示进行中/失败反馈；重新拉取强制获取当前 README。
- 编辑草稿不因重绘或重复点击丢失，自动同步避开编辑；同一容器重复挂载不叠加委托事件。
- 修正阅读页打开 GitHub 时子目录重复拼接。原有 Markdown 安全渲染和首次加入不推历史规则保留。

## 数据与验证边界

沿用现有存储键与 alias/note/icon 字段，不需要数据迁移。
新增真源码委托事件回归测试，覆盖编辑、取消、失败重试、移除确认、同步实际请求、防重入和强制拉取。
另以 Chromium 真 DOM 在 1157px / 390px 宽度检查点击、键盘、菜单和窄屏溢出（模拟 HTTP/存储及宿主主题变量）。
不代表原生 Tauri/Android WebView 或 GitHub 实网验收；本次不生成安装包、不提交 Git。
