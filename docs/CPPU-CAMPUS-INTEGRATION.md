# 警大校园集成接口与验收

## 课程表只读事件
- 请求 `schedule:week-request`: `{ id: string, date: YYYY-MM-DD }`。
- 响应 `schedule:week-response`: `{ id, available, name?, start?, end?, semesterStart?, occurrences?, periods?, unknownPeriods?, error? }`。
- 统计课程表当前选中课表，不静默聚合不同学期的课表。每条当周课程记录算一次；连续节次按结束−开始+1；自定义时间不猜节数。
- 未初始化视图时读取存储快照，不调用会写默认课表的加载过程。保存/切换课表发 `schedule:changed`，校历刷新计数。
- 只传聚合数据，不传教师、地点、课程名、密码和 Cookie。校历自行关联请求 ID，5 秒超时并拒绝迟到响应。

## 校园网页入口
`cppu-webvpn` 专用 `tide.util.openCampusSite("webvpn" | "website")` 需要 `openUrl` 权限。
宿主限制插件 ID，API 固定 HTTPS 官方站点，不接受任意 URL。客户端调用已有 `open_internal`，不修改原生权限边界。
此方案是独立插件工作区 + 原生网页窗口，**不是在主插件 DOM 中嵌入远程网站**。官方账号在原生网页中输入；继续沿 WebVPN 目录访问，浏览器维护认证会话。插件不能推断用户已登录。

## 手动验收
1. 导入单双周、连续多节和自定义时间课程；校历核对课次/节数。切换当前课表、关闭课程表插件再刷新，核对来源、提示与超时。
2. 校历选其他日期，今天所在周仍为红色；校验开学前、末周、跨年和结束后；关闭重开后学期/事项保留。
3. 门户登录设置改为 0、2、5 后重启，检查持久化；模拟首次 HTTP 500 / 网络失败，观察新会话及退避；错误密码和锁定不得连续提交；登录中离开页面不得继续自动重试。
4. Windows 和 Android 从 WebVPN 插件打开官方认证，手动登录后访问有权限的资源；返回插件再进官网。验证网页后退、刷新、关闭；不记录真实密码/票据到测试日志。
5. 在无客户端浏览器环境检查弹窗拦截提示；禁用 WebVPN 插件时门户侧栏导航按宿主不可用视图规则提示。
