# v0.275.0 · 自习室能按楼收窄、顶部那颗「去教务」改名挪位

## 改了什么

只动 `cppu-notify` 插件（`public/plugins/cppu-notify/main.js`，插件版本 1.83.0 → 1.84.0），
三端同源，无数据迁移、无接口变更。

**① 自习室加「楼」胶囊组。** 教务一次返回 17 栋楼（主楼、A/C/D/E、7S/9S/10S、讲堂、阶梯教室…），
全部铺开要滚三屏才看得到自己常去那栋。现在「日期」下面多一行「楼」：`全部 / 主楼 / A 栋 / …`，
选中一栋只留那张卡。

三个数字必须同一个口径，全部按「选中的楼」重算：

| 位置 | 未选楼 | 选了楼 |
|---|---|---|
| 计数行 | `10-21 · 17 栋 214 间 · 空闲位 332 / 630` | `10-21 · 1 栋 32 间 · 空闲位 61 / 96` |
| 卡片标题 | `共 32 间 · 空闲位 61 / 96` | 同左（只留这一张） |
| 搜索计数 | `匹配 3 / 全部 214 间教室` | `匹配 3 / 主楼 32 间教室` |

**卡片是 `[hidden]` 而不是不渲染。** 搜索与节次切换都在 DOM 上就地做（重绘会换掉输入框、
用户打两个字就丢焦点），所以卡片必须一直在树里；选楼后 `jwApplyRoomFilter` 的 scope 也跟着楼走 ——
否则选完楼再打字，别的楼会被搜索「放出来」，而分母还写着全部。

**两处命名必须分开**：胶囊是 `data-room-bld-chip`，卡片是 `data-room-bld`。同名会让
`closest("[data-room-bld]")` 把「点卡片」也当成「点胶囊」，整张卡都不能再点。

**选的楼不在这次数据里**（换了日期、那栋当天全满没返回）自动退回「全部」，否则会渲染出一屏空白。
「楼」这组是单选，同样接了 `tide.ui.selectionGlow`（铁律六），与日期、节次三组共用一次重挂。

**② 顶部工具栏：`刷新 → 回通知 → 重新登录 → 浏览器打开`。** 原来第二颗是「去教务」，
它是这一屏最不常用的动作，却占着最顺手的位置；现在改名「浏览器打开」并挪到最右。
按钮仍是同一颗 `data-jw-site`、同一个 `openSideLink(JW_INDEX)` 免密通道，只是文案与位置变了。
自习室 / 考试两页的空态文案一并改成「点『浏览器打开』」——按钮改了名，正文不能还叫旧名。

## 回归断言

`scripts/test-cppu.mjs` 新增五条，钉住「半成品」的三种写法：

- 楼胶囊组与每颗 `data-room-bld-chip` 都在（属性名不许与卡片的 `data-room-bld` 撞）
- 卡片按 `visible` 收起，且过滤时 `card.hidden` 必须**叠加**楼选择
- `jwSyncRoomGlow` 的 selector 必须含 `[data-room-blds]`（少一个 = 少了滑动光）
- 工具栏里 `data-jw-back` 必须在 `data-jw-site` 之前，且不再出现 `>去教务<`
