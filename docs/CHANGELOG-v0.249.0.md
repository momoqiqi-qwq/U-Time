# v0.249.0 — 界面点缀：空状态线稿 · 来源图标 · 规则开关 · 节奏标签 · 字标重画

影响端：桌面端（Windows）与 Android（同一套前端）；小程序不受影响。无数据迁移。

## 新增

### 空状态线稿插画（新模块 `src/emptyArt.js`）
- 手绘细线 + 一处实心强调色 + 小星星，风格取自选定参考稿。内联 SVG：线条走 `currentColor`，强调色走 `--ea-accent`，浅色 / 深色 / 各套主题色自动跟随，不出图片文件。
- **四象限**：象限里一条任务都没有时显示各自的插画与一句话（I 纸飞机「别再犹豫」/ II 硬币→芽「复利」/ III 捆成一摞的信封「批量」/ IV 热茶与月亮「休息」）。强调色取各象限的 `--q1…--q4`。被搜索或筛选筛空时**不**显示（那时说「别再犹豫」不对）。
- **收件箱清空**：空托盘 + 勾，替换原来的「没有待处理事项。」。
- **插件**（各自内联一份 SVG，插件不能 import 宿主源码）：周报「这 7 天还没有时间块」、RSS「还没有订阅源」、学校通知「先输入学校通知网站网址」。

### 收件箱来源图标（16px）
- 插件经 `tide.inbox.create` 推进来的条目现在会带上 `sourcePlugin`（`pluginHost.js`），收件箱用与侧栏同一张插件图标。
- 旧条目只有 `source` 文案：按内置插件名反查（全名或前缀，如「警大门户通知」）。
- 没有插件来源的（AI 自动任务 / 内置规则）给一个内联小图形（AI = 双星，规则 = 闪电），整列对齐。

### 自动化规则：规则图标 + 真正的开关
- 每条规则左侧一个 32px 圆角图标（截止排程 = 日历、考试提醒 = 铃铛、课程同步 = 循环箭头、每日整理 = 闪光），颜色按 `data-action` 给。关掉的规则图标变灰。
- 修复：`styles.css` 的旧规则 `.automation-rule input{width:18px;height:18px}` 是给原生勾格写的，换成滑块开关后把 36×20 的开关压成了 18×18 —— 只剩一颗紫色圆点，看起来像单选框。现在按 `.switch` 自己的尺寸变量还原，与插件中心的开关一致。

### 时间块「近 7 天节奏」
- 星期标签其实一直在 DOM 里，但柱子 `overflow:hidden` 把 `bottom:-17px` 的标签裁掉了 —— 现在可见。
- 正在查看的那天（`cur`）用海蓝底 + 描边 + 粗体标签高亮；真正的今天（`today`）标签下加一个珊瑚色小点。悬停显示「周几 · 已排 X」。
- 柱子底色从写死的 `#EFEAE1 / #DCEAEF` 改为主题变量（深色主题下不再是两根奶白条）。

### 字标装饰线重画
- 切到另一个视图时，侧栏字标下的装饰线从中间向两侧重新描一遍，卷草随后弹出（约 0.6s）。
- 系统「减少动态效果」或设置里选了减少动态时完全不播（JS 不加类 + CSS 兜底）。
- `brandRule()` 签名不变（仍零必填参数）；两条主线加了 `pathLength="1"` 与 `data-side="l|r"`（类名保持 `br-line` 不变，test-brand-wordmark 按它找形状）。

## 实现说明
- 新样式集中在 `src/styles/ui-accents.css`（`index.html` 在 plugin-polish.css 之后引入），没有动 `styles.css`，因此不需要重生成 theme-derived.css。
- 插件版本：weekly-report 0.2.0 → 0.2.1、rss-reader 1.9.0 → 1.9.1、school-notice 1.9.0 → 1.9.1（`pluginCatalog.js` 由 sync-plugins.js 重新生成）。
- 新测试 `scripts/test-ui-accents.mjs`：线稿只用 currentColor / 变量、四象限与收件箱都接了插画、三个插件各自内联、规则开关尺寸覆盖、节奏柱不再写死颜色、字标重画尊重减少动态。
