# v0.271.0 · 警大选课：已选课程卡片标出「剩余学时」

## 改了什么

`public/plugins/cppu-notify/`（插件版本 1.80.0 → 1.81.0）

1. **已选课程卡片新增一枚「剩余 N 学时」标签**
   - 选课结果视图（`V_JWBZK_XKGL_XKJG`）的 18 个字段里**只有 `XF` 学分、没有学时**，
     所以课时借请假视图那张课次表（`V_JWBZK_PK_XSKBZHCX`）：`KCH`/`KCBH` 课程号、
     `KXXS` 课序学时、`SKRQ` 上课日。
   - 口径：总学时 = Σ 该课每次课的 `KXXS`；已上 = `SKRQ ≤ 今天` 的那些课次；
     剩余 = 总 − 已上（`Math.max(0, …)`）。
   - 对齐按课程号（`KCH` 优先、`KCBH` 兜底）；**课次行没给号时才退回课程名**，
     否则一门缺号的课会把整学期学时算到自己头上。
   - 剩余为 0 显示「学时已上完」，不出「剩余 0 学时」这种读不通的文案；
     课次表为空 / 匹配不到 / `KXXS` 全缺 → **一枚标签都不显示**。
     慕课这类没排课次的课程就是这一条：绝不拿学分折算一个「看起来像」的数
     （学分与学时不是一回事，慕课尤其不是）。
2. **选课视图多拉一个 `qjCourse`**（`keys: ["xkTask", "xkResult", "qjCourse"]`）
   - 已选课程要算学时就得有课次；`jwEnsureKeys` 对 `qjCourse` 本来就会附
     `XNXQ_CODE = 当前学期` 的条件（整学期一次拉全，实测 222 节）。
   - 拉不到只影响那枚标签，选课表和请假页都不受牵连（错误按 key 分别落）。
3. **样式只加一条、不加新色相**
   - `.jw-tag.hours{font-weight:700;border-color:color-mix(in srgb,var(--deep) 34%,var(--line))}`
   - 文字色沿用 `.jw-tag` 的默认 `var(--deep)` —— 16 套主题的浅/深两态都已实测达标；
     硬编码色一条不加，`test-theme-contrast.mjs` 里「`.jw-tag.ok/.warn/.live` 恰好 3 条
     硬编码浅色」的计数不被碰。
4. **文案**：视图 `tip` 说明学时是按课次算的、慕课不显示。

## 回归断言（`scripts/test-cppu.mjs` §12）

- `jwHoursRest` 的 total / done / rest 三个数（后半个学期没上的课次不算已上）
- 卡片出 `class="jw-tag hours">剩余 2 学时`
- 没排课次的课程**一枚都没有**（整页只允许出现一次「剩余 N 学时」）
- 剩余 0 → 「学时已上完」，且不出现「剩余 0 学时」
- 课次行缺课程号时按课程名对齐
- 课次表为空 → `null`（不下结论）
- `cppu-xk` 的 `keys` 必须含 `qjCourse`
