# v0.165.0

- 界面与交互设置新增「番茄计时卡液态玻璃」开关，默认关闭，偏好随应用数据保存。
- 番茄专注插件升级至 0.7.0，在计时卡头部新增设置按钮，直接定位到液态玻璃开关。
- 开启时使用本地背景纹理与 GLSL 折射、散射、高光、圆角裁切绘制单张计时卡；计时与按钮保留清晰 DOM。
- 桌面/Android 共用前端实现；Android 降低渲染分辨率并禁用多方向散射。小程序保留既有原生计时器，本次不增加 GLSL 材质。
- 后台/不可见时暂停渲染，减少动效时静态绘制；关掉效果、离开插件或停用插件时释放 GPU 资源。WebGL 不可用时回退原卡片。
- 现有任务、计时记录、提醒配置无迁移。第三方 GLSL 的来源及本地使用边界见 `src/shaders/ATTRIBUTION.md`。
