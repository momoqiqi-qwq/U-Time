# v0.159.0

## 导出成绩单

- 修复「警大门户通知 → 警大学分 → 导出成绩单」在 Windows 桌面端点「生成并分享成绩单图片」后弹出空白系统共享面板（界面显示「重试 / 我们无法为你显示所有共享方法」）、且图片永远不会保存的问题。
- 根因：分享分支的判据是 `navigator.share && (!navigator.canShare || navigator.canShare({files}))`，`||` 前半段等于「缺少能力校验接口就放行」。桌面端 WebView 里 `navigator.share` 存在但未实现文件分享，`navigator.canShare` 也不存在，于是进了分享分支并弹出无法退出的空面板，后面的宿主机落盘兜底（`tide.assets.saveBase64`）被整个截胡。
- 修法：只信 `canShare` 的正向结论 —— `navigator.canShare` 与 `navigator.share` 同时为函数、且 `canShare({files})` 返回 true 才走原生分享，否则一律回落到宿主机下载桥保存 PNG。
- 补 `test-cppu` 断言（无 `canShare` / `canShare=false` 必须落盘且不调用分享、`canShare=true` 走分享且不重复落盘、用户取消分享时静默返回），变异验证可拦住回退。

## 通知筛选面板

- 修复「警大门户通知」筛选面板的一组问题：搜索框里残留关键词时，点分类/月份的「全部」永远清不掉它（关键词不在面板里），列表一直「显示 0 条」却看不出原因，像筛选坏了；筛选面板没有「恢复默认」的出路。
- 筛选面板新增「恢复默认筛选」按钮：一键整体重置关键词、分类、年份、月份与只看未读（关键词本来就存在 `filter` 状态里，必须整体重置才清得掉）。列表空态也给出同样的按钮，并在有关键词时直接点名「关键词「xx」没有匹配」，不再只说"没有符合过滤条件的通知"。
- 筛选面板新增「年份」行（全部 / 2026年 / …）：此前只有月粒度，筛不了"某一年全年"；月份行在选定年份后只显示该年的月份。切换年份时若已选月份不属于该年，自动清掉，避免「2025年 + 2026年9月」这种恒空的组合。
- 修复筛选结果为 0 时「加载更早的通知」按钮也一起消失的问题：空态分支提前 return 把分页入口锁死，老数据永远够不着。现在空态下仍可「加载更早的通知再筛」，并且会连页往回拉直到出现匹配（`loadOlderUntilMatch`）。
- 修复筛选下拉点面板外面不收回的问题：原生 `<details>` 不会自动收，现在在文档级捕获外部按下替它收起（`pointerdown` 捕获段，重进插件时替换旧监听）。
- 回答「消息有 50 条的限制吗」：单页 50 条是门户接口的页大小，不是上限 —— 列表底部可继续「加载更早的通知」，最多 10 页共 500 条；此前的问题在于筛选为 0 时入口消失，现已修复。
- 补 `test-cppu` 断言：年份筛选只留匹配年（时间未知项不冒充任何年份）、默认筛选含 `year` 维度、`data-years` / `data-filter-reset` / 点外部收起 / `loadOlderUntilMatch` 必须存在，变异验证可拦住回退。

## 说明

- 影响 Windows、Android 与小程序的 `cppu-notify` 插件（插件版本 1.34.2 → 1.35.0）；无数据迁移（旧的已保存筛选缺 `year` 字段，按默认「全部」处理）。
